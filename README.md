# Solar Simulator

## О проекте

Что ты собираешься создать и зачем.

## Что изучено

- Научная запись больших и малых чисел
- Особенности хранения чисел типа float
- Абсолютная и относительная погрешность
- Основные единицы измерения SI
- Основы виртуальных окружений и Git

## Что уже реализовано

- Расчёт координаты объекта при равномерном прямолинейном движении
- Создание массивов времени и координат с помощью NumPy
- Визуализация зависимости координаты от времени с помощью Matplotlib
- Автоматические тесты функции расчёта с помощью pytest
## Используемые технологии

- Python
- NumPy
- Matplotlib
- pytest
