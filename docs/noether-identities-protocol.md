# Мгновенные Noether-тождества по порядкам

16 октября 2026. Протокол 223, до новых измерений. Блок 223–228.
Неизменные 30 снимков пилота220: три уровня reference и три кандидата,
по пять эпох за трое суток. SI, исходные SSB/Ecliptic J2000/Origin,
точные сохранённые float64 массы, G, c и тензоры Q. Новых траекторий нет.
Прежний критерий различимости глобальных бюджетов FAILED не переоценивается.

Основание: [Vines, EIH действие на стр.3](https://fiteoweb.unige.ch/~maggiore/GWVol1/EIHLagrangian.pdf),
[Park et al. 2021, §3.1–3.2](https://ssd.jpl.nasa.gov/doc/Park.2021.AJ.DE440.pdf).
Вводим лишь формальные метки порядков λ и η, не новые параметры runtime:
L=L_N+λL_PN−ηV2, a=a_N+λa_PN+ηa_Q,
F=(E,P,J)=F_N+λF_PN+η(V2,0,0).
Здесь L_PN и a_PN уже включают физический c^-2.

Обозначим D_p/D_v направленные производные, p'=v. Проверяются:

1. D_pF_N[v]+D_vF_N[a_N]=0.
2. D_pF_PN[v]+D_vF_PN[a_N]+D_vF_N[a_PN]=0.
3. D_p(V2,0,0)[v]+D_vF_N[a_Q]=(0,0,τ_Q).
4. D_vF_PN[a_PN]=(Σv·R2,ΣR2,Σr×R2), R2=H_PN a_PN.
5. D_vF_PN[a_Q]=(Σv·Rmix,ΣRmix,Σr×Rmix), Rmix=H_PN a_Q.

H_PN — гессиан L_PN по скоростям. Правые части PN²/PN×Q являются
bookkeeping существующих усечённых уравнений, не новыми физическими силами.
Все E/P/J и силы для математической проверки вычисляются в Decimal
независимыми скалярными циклами; не подставлять округлённую total float force.
Направленные производные вычислять центральной разностью отдельных частей,
а не полных E/P/J. Decimal-сдвиги не преобразовывать обратно в float.

## Заранее заданные критерии

Точность Decimal 70 и 90 цифр. Шаги производной в SI-секундах:
h=1e-3,1e-5,1e-7. Сохранить все уровни, не выбирать лучший по результату.
Для каждого тождества оценить энергию, вектор P и вектор J отдельно.
Пороги последнего h: нормированный дефект <1e-8;
изменение между последними h <1e-8; изменение 70→90 цифр <1e-30.

Для нулевых правых частей масштабы брать из не сокращённых вкладов:
Σm|v||b|, Σm|b|, Σ|r|m|b| при b=a_N, a_PN или a_Q соответственно.
Для PN²/PN×Q: Σ|v||R|, Σ|R|, Σ|r||R| и дополнительно относительный
дефект к норме каждого ненулевого целевого E/P/J блока <1e-8.
Точные нули обрабатывать отдельно; не добавлять epsilon или скрывать блок.
Для сравнения точностей тот же масштаб и ненулевой целевой сигнал;
порог 1e-30 применяется к обоим нормированным дефектам.

Отрицательные контроли, не варианты физики:
- убрать реакции a_Q на Sun/Earth: хотя бы один дефект >1e-3;
- убрать static U_i² часть PN-энергии: дефект энергии >1e-3;
- заменить полную a_PN суммой изолированных пар: дефект >1e-6;
- исключить PN² или PN×Q источник: относительный дефект >.9
  для каждого ненулевого E/P/J блока.
Первые три контроля должны сработать хотя бы в одном из пяти снимков
каждого набора; все снимки сохраняются, неудобные эпохи не исключаются.

Перед 30 снимками проверить сумму частей против прежнего Decimal readout,
аналитику Newton pair, отсутствие округления малых Decimal-сдвигов,
согласие независимых Decimal сил с прежними раздельными float выражениями.
Критерии моста: Newton/J2/отдельная matrix-PN <5e-13 относительно норм
сил; полная native EIH <3e-14; усиленная native PN при c/10 <3e-9.
Источники float против Decimal: каждый ненулевой E/P/J блок <5e-10
относительно своего сигнала, не суммарного Newtonian масштаба.

Фиксировать SHA кода/снимков/реальных зависимостей; не менять исполняемые
исходники до окончания аудита. Записать цену математической проверки и моста
отдельно. Отказы сохранить без изменения порогов. Нет нового JPL, новой
оценки ошибок орбит, годовых балансов, вращения, приливов или изменения ядра.
