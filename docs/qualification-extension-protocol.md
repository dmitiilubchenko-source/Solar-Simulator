# Протокол расширенной квалификации138–141

14 октября2026, до измерений. Формулы и runtime не меняются до обоснованной
проверки кандидата. Все прежние отчёты, входы и неуспехи сохраняются.

1. **J2:** фиксированные Sun/Earth,10тел, исходный `solar_sandbox`, SI,
   EclipticJ2000/SSB/JD2461321.5TDB. Кандидат пропускает вычисление тензора
   только в ветке фиксированной оси; сила и реакция вычисляются прежним
   выражением. Заданные оси сохраняют тензорный путь.1000вызовов×5повторов,
   прогрев; полный50-дневный расчёт60пакетов×20×3600с,3повтора с прогревом.
   Порядок old/candidate чередуется. Требуется точное совпадение сил и JSON
   checkpoint; старые независимые J2/Q2 тесты остаются обязательными.
   Практический порог внедрения:≥15% уменьшения медианы полного расчёта,
   чтобы оправдать смену научной версии и повторную квалификацию. Этот порог
   — инженерный выбор, не физическая константа. Меньший выигрыш записать;
   допустимо оставить более простой runtime. Тайминги с профилированием отдельно.
2. **JPL:** заранее выбранная расширенная сетка: первые32суток с шагом0.5суток,
   далее еженедельно до года, все прежние45эпох и точный конец365.25суток.
   Все10тел по одним эпохам; новые ответы Horizons геометрические DE441,
   SSB/EclipticJ2000/TDB/KM-S с явным переводом в SI, без подгонки старта.
   Входные GM/координаты/скорости runtime прежние. Проверить исходную эпоху
   и совпадающие старые эпохи в пределах0.01м/1e-8м/с, происхождение/SHA.
   Цели прежние:<10км/тело и<1км Moon−Earth. Численная чувствительность:
   DOP853 rtol1e-13 против3e-14 при прежних atol, dt3600с, max_steps20;
   <10м/тело, <0.1м для относительной Луны. Энергетический остаток<1e-10
   лишь для соответствующего усечения EIH+J2; весь орбитальный L не сохраняется.
   Эта сетка расширяет область измерений, не даёт непрерывной гарантии.
   При недоступности сети сохранить отказ и выполнить независимые локальные
   проверки; не объявлять новые JPL точки проверенными.
3. **Изменённые системы:** наклонные ньютоновские пары без J2/контактов:
   изменение массы×2, скорости×0.7/×1.8 (связанный/несвязанный исход),
   эксцентриситет0.95, добавление второго тела и удаление первичного.
   33эпохи/один период связанных случаев, несвязанный — время1e6с.
   Эталон: собственное решение уравнения Кеплера бисекцией для эллипса;
   для гиперболы независимый RK45 и два уровня rtol/максимального шага.
   DOP853 Python/Rust, rtol1e-13/atol1e-3м и1e-9м/с. Ошибки относительно
   эталона:<10м/1e-5м/с; эталон гиперболы<1м/1e-6м/с между уровнями;
   относительные E/L и нормированный P<1e-10. Для удаления первичного
   аналитическое свободное движение и сохранность родителя. Никакого JPL
   утверждения для пользовательских систем. Экстремальная пара не сертификат
   всех тесных сближений. Отказ внутри опорного радиуса J2 проверить отдельно.
4. **Демонстрация:** одна команда для короткой аналитической проверки,
   реального runtime J2, сохранения/загрузки/продолжения/ветки/CSV и строгой
   проверки SHA актуальных научных отчётов. Отдельно полный `check_project`,
   новая portable и реальная изолированная распаковка. Быстрый запуск не
   заменяет годовую проверку и полный тестовый набор.

Источник принятой фигуры и ограничений: [Park et al.,2021,§3.2](https://ssd.jpl.nasa.gov/doc/Park.2021.AJ.DE440.pdf),
[существующие соглашения](oblateness.md), [исходная квалификация](sandbox-demo-protocol.md).
Consensus доступен; первичная статья прочитана напрямую с JPL. Новые приливы,
вращение, столкновения, графика и абстракции физических моделей не добавляются.
