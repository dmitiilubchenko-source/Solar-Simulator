Принятый выпуск — 0.3.2. Исследования в dev не означают готовность следующего
выпуска. Актуальные компоненты перечислены в [короткой карте](project-map.md).

Многие JSON/NPZ и научные отчёты пока сохраняют исторические пути в корне
docs: на них ссылаются код, контрольные суммы и воспроизводимые проверки.
Разделы выше дают прямые ссылки на действующие материалы; старые доказательства
не переписываются и не перемещаются только ради внешнего порядка.

Для самостоятельных частей кода есть локальные README: [Python-пакет](../src/solar_simulator/README.md),
[Rust core](../rust/solar_core/README.md), [Python/Rust мост](../rust/solar_native/README.md),
[экспериментальный Rust solver](../rust/solar_adaptive/README.md) и
[приёмка песочницы](../scripts/sandbox_checks/README.md).
