
# 410R-v2 — техническая приёмка portable 0.4.0

**TECHNICAL PORTABLE ACCEPTANCE GO** для точного неизменённого ZIP
Solar-Simulator 0.4.0, проверенного Windows-хоста и указанной научной
области. Израсходована одна из одной разрешённой попытки. Исходная
preflight-остановка 410R сохранена. **RELEASE_READINESS = NO_GO** до
отдельного решения владельца. [Машинный отчёт](portable-acceptance-410r-v2.json).

Preflight проверил размер ZIP 114 633 711 байт, CRC и SHA всех 6005
элементов и pass внешних привязок из amendment 410E. Python из архива
прошёл реальный запуск с `-I -B` во вложенной Windows Job, загрузил
нативное расширение cp314t и writer и открыл эталонный NPZ. Синтетические
binary64 сравнения годовых и относительных норм дали точное совпадение.
Отдельная запись прошла с Unicode путём, изолированными окружением и cwd.
[План](../scripts/qualification410r-v2/execution-plan.json) ·
[Preflight](../scripts/qualification410r-v2/preflight.json).

Штатный wrapper выполнил GUI, сохранение, паузу и продолжение,
parent/branch, recovery и запись/воспроизведение при Python и Rust.
CLI CSV и обработка I/O отказов прошли. Проверено 587 ссылок и наличие
44 файлов лицензий в runtime. Старый кадр 0.3.2 со схемой 10 прочитан
поставляемым loader. В read-only проверке тот же packaged метод
формирования текста панели показал предупреждение для двух динамических
Q2 и сохранил разграничение для 0 и 1 фигуры. Дополнительное окно не
создавалось. Supervisor подтвердил exit 0, пустую Job и атомарную
квитанцию. Все 19 учтённых PID проверены по creation FILETIME.
[Исполнение и аудит](../scripts/qualification410r-v2/independent-audit.json).

квитанции израсходовал 92,984375 CPU-секунды, вызывающий процесс вместе
с записью — 93,890625 CPU-секунды. Wall worker 146,38 с. С preflight и
аудитом измерено 250,75 CPU-секунды и 162,91 с активного времени. Пики
из выборок составили 517 722 112 байт private и 330 952 877 байт
контролируемого диска. Preflight и worker вместе занимали 651 340 038
байт. Журнал отделяет измерения, allowances и прошлые стадии. Ранняя
остановка не сработала, бюджет сохранён.
