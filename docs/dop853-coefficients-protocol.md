# Алгебраическая диагностика таблицы DOP853: протокол346

21 октября2026, до новых численных результатов. Это исследование таблицы,
не изменение интегратора. Исходные Rust335 5PASS/4FAIL и все результаты
[shadow338](rust-adaptive-shadow-validation.md)/[refinement339](rust-adaptive-refinement-validation.md)
сохраняются. Никаких новых орбит, шага, допусков или подбора коэффициентов.

Исходник SciPy1.18.1 `dop853_coefficients.py` уже закреплён в
[сверке334](rust-adaptive-source-review.json): SHA256
`e283219a0f1e5f2cc37924ab961d9d24932f69a6d69fe68ee384b7c31f08839a`.
До расчёта проверить эти байты. AST извлекает исходные десятичные литералы
без превращения в float и без исполнения файла. A=первые12×12, B=строка12,
C=первые12; dense output, E3/E5 и адаптация не входят в данный анализ.
Округление A/B/C в binary64 должно побитно совпасть со168 Rust-значениями;
оставшиеся26 E3/E5 не исследуются. При расхождении остановиться явно.

Теория: J.C.Butcher, H.Podhaisky, [Isomeric trees and the order of
Runge–Kutta methods](https://arxiv.org/abs/2112.01608v1), раздел2, (6)–(8).
Для автономной векторной задачи y′=f(y), как у Newton2point, перечислить
все неупорядоченные корневые деревья порядков1…8: 1,1,2,4,9,20,48,115.
Лист имеет stage weight1; узел — покомпонентное произведение A·weight
каждой ветви. Phi(t)=b·weight(t), gamma(t)=|t|×product(gamma(children)).
Сохранить все точные рациональные Phi(t)−1/gamma(t), без симметрийного
нормировочного множителя. Это условия автономной векторной задачи;
одной скалярной линейной задачи для полного порядка недостаточно.

Два набора: исходные конечные десятичные литералы как exact rationals и
их exact binary64 значения. Сохранить все невязки, их максимумы по порядку,
sum(A_i)−C_i, sum(B)−1. Отдельный linear-chain recurrence даёт
b·A^(k−1)·1−1/k!, k=1…8. Нового порога «порядок8 PASS» нет: конечные
литералы также округлены; малые остатки не доказывают точный порядок
идеального метода и не являются метрами ошибки орбиты.

Независимые проверки программы: рациональные Euler, midpoint, классический
RK4; явные восемь условий порядков1…4 и цепочки до8; повреждение pinned
источника, неявная таблица, дубликат A, отказ перезаписи. Сохранить SHA кода,
протокола и входов, baseline Git и стоимость. Исторические файлы не менять.

Первичный [код Hairer/Wanner](https://www.unige.ch/~hairer/prog/nonstiff/dop853.f)
один раз прочитан через web, но прямое получение raw возвращает503;
повтор через web также503. Его rawSHA и совпадение литералов с SciPy
в этом этапе не установлены. Не публиковать выдуманную привязку к Hairer.
Для текущей таблицы первичным программным источником остаётся pinnedSciPy;
BSD notice: `rust/solar_adaptive/LICENSE-SCIPY.txt`.

По результату допустим только вывод о наличии/масштабе алгебраических
остатков. Причинное объяснение орбитальных FAIL потребует отдельного
протокола с прежними IC/GM/сетками/oracle и единственным изменением таблицы
в Decimal-shadow. Подключение к runtime и квалификация 10тел/год запрещены
только на основании данного исследования.
