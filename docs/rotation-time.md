# Время, совместимые величины и начальное вращение — изменение 64

Проверены равномерное масштабирование выбранного finite H57 и кинематика
вращения при **явно заданных** часах и движении базиса. Все критерии
[протокола](../scripts/rotation-time-policy.json) прошли:
[неизменяемый результат](rotation-time-validation.json).
Рабочий Newton/rigid-режим и старые данные не изменены. Физический перенос
DE441 в полный PN/rigid-базис остаётся **не сертифицирован**.

## Проверенные первичные источники

- [Klioner, Relativistic scaling of astronomical quantities (2008)](https://arxiv.org/pdf/astro-ph/0508292),
  §3.2–3.3, уравнения 7–9: линейная связь TCB/TDB требует согласованного
  масштабирования координат и GM. Это разные совместимые величины,
  выраженные в одинаковых SI-единицах.
- [Klioner, Gerlach, Soffel, Relativistic aspects of rotational motion (2010)](https://arxiv.org/pdf/1001.0915),
  §2 и §7: модель вращающихся мультиполей, локальная система и PN-инерция;
  уравнения 7.3–7.4 учитывают первую и вторую производные времени,
  7.5–7.9 описывают совместимые GM, длины и кубический масштаб инерции.
  Земной пример не определяет происхождение радиуса/инерции Луны.
- [IAU NSFA, defining constants](https://iau-a3.gitlab.io/NSFA/NSFA_fixed):
  точная определяющая константа (L_B=1.550519768·10^{-8}), IAU2006 B3.
- [Park et al., DE440/DE441 (2021)](https://ssd.jpl.nasa.gov/doc/Park.2021.AJ.DE440.pdf),
  §4.1–4.2: ориентация мантии, жидкое ядро, изменяющаяся инерция и
  геодезическая прецессия. Постоянная эффективная инерция нашего профиля
  не воспроизводит эту модель целиком.

Consensus доступен: поиск и fetch статьи

## Равномерное масштабирование выбранного H

При (t_*=Ft, x_*=Fx, GM_*=F,GM), неизменных G и c и **совместимых**
числах в одинаковых единицах получаем для нашего конечного гамильтониана:

| Величина | Масштаб |
| --- | --- |
| модельная масса GM/G, канонический p | F |
| пространственный S, общий J | F² |
| I | F³ |
| ограничивающий радиус | F |
| q, dx/dt, c | 1 |
| W, ускорение координат | 1/F |
| H, общий P | F |

Последние степени для p/S/I/H выведены здесь из однородности **именно H57**:
кинетическая орбитальная энергия, ADM1PN, LO spin–orbit, Newton rotor и Q2
получают общий множитель F. Для состояния (y_*=D_Fy) проверяется

\[
f_*(t_*,y_*)=D_F f(t,y)/F.
\]

Каноническая однозначная форма действия (p·dx+S·d\theta-Hdt)
получает F². Поэтому это не каноническое преобразование при неизменных
симплектических единицах. Смена SI similarity-баз тоже проверена отдельно;
она не подменяет физическое преобразование TCB/TDB.

Реализация
[UniformTimeScaling](C:/Users/Admin/Desktop/Solar-simulator/scripts/rotation_time.py:24)
сохраняет сырые q, отвергает нечисловой/непредставимый F и проверяет
допустимость исходного и преобразованного состояния. Это исследовательская
операция, без сохранения нового lunar-checkpoint и без изменения профиля.

## Заданные часы и движущийся базис

Пусть B — явно заданное ортогональное отображение локальной евклидовой
триады в глобальную, (r=dT/dt>0), (R_g=B R_l(T)). Обычное правило
цепочки и произведения даёт:

\[
\dot R_g=\dot B R_l+rB R_{l,T},\qquad
W_g=W_B+rB W_l,
\]
\[
\dot W_g=\dot W_B+\dot r B W_l+r W_B\times(B W_l)+r^2B W_{l,T}.
\]

Проверяются SO(3), касательность производных, конечность и положительный
r: [spatial_rate](C:/Users/Admin/Desktop/Solar-simulator/scripts/rotation_time.py:58),
[rotation_boundary](C:/Users/Admin/Desktop/Solar-simulator/scripts/rotation_time.py:71),
[обратная скорость](C:/Users/Admin/Desktop/Solar-simulator/scripts/rotation_time.py:85),
[ускорение](C:/Users/Admin/Desktop/Solar-simulator/scripts/rotation_time.py:92).
B не является metric-spin square root из изменения58: такой корень
вообще не обязан быть ортогональным и здесь отклоняется. Функции не
вычисляют часы Луны, метрический тетрадный перенос или прецессию из эфемерид.

## Найденные отказы и причины

1. Первый новый тест:15passed/1failed,1.51s. Неверный контроль при F=0.5
   сохранял I, хотя уменьшенные mass/R уже не позволяли поместить её
   в ограничивающую сферу. RigidFigure правильно отверг объект.
   Контроль переведён на F=2 из исходного набора масштабов, явно добавлен
   wrong_inertia_factor; критерии не менялись. Источник/протокол/отказ
   сохранены `.tools/rotation64/control-construction-failure/`.
2. Первый аудит: оба расчёта завершились, JSON-запись оборвалась на np.bool_.
   Источники, неполный отчёт и оба массива сохранены
   `.tools/rotation64/report-serialization-failure/`. Исправлено явное
   получение Python float/bool, добавлен тест сериализации результатов;
   JSON формируется до открытия нового файла. Новый аудит выполнен заново,
   исходный неуспех не переписан. Численные критерии не менялись.

## Физический договор дальнейшего переноса Луны

Исходный профиль содержит PA→EclipticJ2000 R и **глобальную TDB-производную**
на JD2461321.5, GM из DE441 и эффективную постоянную инерцию из GM/G,
1738km и опубликованной средней solid-инерции. Эта структура не становится
локальной скоростью только потому, что её использует rotor. Применять к
ней Bdot/clock ещё раз без определения провайдера означало бы риск двойного
учёта. Совместная инверсия58 уже согласует заданную W с полным выбранным H;
повторно добавлять LO SO к ней нельзя.

| Нужное соглашение | Что ещё требуется |
| --- | --- |
| время и GM | выбранная глобальная шкала; доказанное происхождение локальной шкалы/часов при её использовании |
| инерция и радиус | совместимость шкалы, SI и GM; effective solid/total/undistorted/PN различия; модель постоянства I |
| ориентация и спин | определение локальной триады, тетрады и глобального канонического spin/SSC; отсутствие двойного учёта связи |
| центр и импульс | согласованный PN-перенос центров/скоростей и SSC; LO сдвиг58 недостаточен для полного тела |
| уравнения | порядок и полный состав PN-extended-body членов; H57 содержит только Newton rotor/Q2 поверх point1PN/LOSO |
| прогноз | свободный расчёт, отдельная численная неопределённость и затем отложенная внешняя проверка |

Диагностические примеры при **гипотетическом** обратном uniform scaling:
mass относительное1.55052e−8, I4.65156e−8, S3.10104e−8;
1738km изменились бы на0.026948m, длительность32TDB-суток на0.042869s.
Это масштабы соглашений, **не исправления действительного профиля**.
Происхождение его radius/I пока не позволяет выбрать такой перенос.
Не создавалась физическая TCB-модель и не объяснён остаток121.84″/год.
Кольцо Койпера остаётся экспериментальным; результаты64 его не сертифицируют.

для границы начальных данных, с отклонением неподтверждённых физических
переносов. Полный PN-runtime требует отдельного сквозного аудита.
Приливы, ядро и деформация не добавлены; консервативные условия остаются
