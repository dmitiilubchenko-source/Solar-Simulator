# Пользователю

1. [Руководство](../user-guide.md): запуск, сценарии, управление расчётом,
   сохранение и ограничения режимов.

3. [Выбор профиля](../profile-selection.md): различие настроек и области проверки.

Для конкретной задачи:

| Задача | Инструкция |
|---|---|
| Изменить тело и выбрать единицы | [Редактор](../body-editor-units.md) |
| Понять parent/child опыта | [Ветки](../sandbox-experiments.md) |
| Записать и смотреть траекторию | [Запись и просмотр](../trajectory-recording.md) |
| Сравнить исходный и изменённый опыт | [Сравнение](../trajectory-comparison.md) |
| Безопасно остановиться и восстановиться | [Остановка и recovery](../controlled-stop.md) |
| Повторить расчёт по рецепту | [Recipe/replay](../recording-recipe.md) |

Показанные размеры маркеров не являются физическими радиусами. Изменение
параметров создаёт новый эксперимент; точность исходного профиля автоматически
не переносится на изменённую систему. Область подтверждённой точности —
в [разделе проверок](../verification/README.md).
