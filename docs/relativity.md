# Релятивистское движение: EIH 1PN

Текущая версия для разработки поддерживает две явно выбираемые модели:
`newtonian` и `eih-1pn`. По умолчанию остаётся ньютоновская физика.
Первый постньютоновский порядок учитывает поправки пропорциональные 1/c²;
это приближение ОТО для слабого поля и медленных массивных точечных тел.
Скорость света c = 299792458 м/с, единицы остальных величин — SI.

## Уравнения и применимость

Используются уравнения Эйнштейна—Инфельда—Гофмана (EIH) в гармонических
координатах для всех тел. Солнце также ускоряется. Поправки зависят от
скоростей, потенциалов всех остальных тел и ускорений источников.
В последних подставляются ньютоновские ускорения: это согласованное
сокращение до порядка 1/c². Итеративное включение поправленных ускорений
добавило бы отдельные члены следующего порядка без полной модели 2PN.

Первичный источник лагранжиана:
[Justin Vines, EIH action, стр. 3](https://fiteoweb.unige.ch/~maggiore/GWVol1/EIHLagrangian.pdf).
Ускорения сопоставлены с опубликованными уравнениями в
[REBOUNDx gr_full](https://github.com/dtamayo/reboundx/blob/502abf3066d9bae174cb20538294c916e73391cd/src/gr_full.c)
и [описанием GR в jorbit](https://jorbit.readthedocs.io/en/latest/core/accelerations/gr_accelerations.html).
Наша реализация использует NumPy и сокращение до 1PN.

В пределе малой массы спутника и неподвижного центрального тела:

```text
a = -μ r/r³ + μ/(c²r³) [(4μ/r - v²) r + 4(r·v) v]
```

Здесь r и v — относительные векторы. Это контрольный предел, а не
замена полной N-тельной формулы в приложении. Поправка только к потенциалу
не подходит для наших целей: у неё отличается среднее орбитальное движение,
как поясняет [документация REBOUNDx](https://reboundx.readthedocs.io/en/stable/effects.html#gr-potential).

Программная граница: для каждого тела U/c² < 1e-4 и v²/c² < 1e-4;
U = Σⱼ≠ᵢ Gmⱼ/rᵢⱼ. Превышение прекращает расчёт, включая внутренние
стадии интегратора. Этот порог ограничивает режим применения, но не
гарантирует заданную физическую точность. Допускаются только нулевые
радиусы и spin. Нет 2PN, гравитационного излучения, влияния вращения,
приливов, несферичности, контактной или гидродинамической физики.

## Сохранения и система отсчёта

1PN работает через Python/DOP853. Существующий Velocity Verlet рассчитан
на ускорения, зависящие от положения; сочетание 1PN/Verlet/Rust отклоняется
явно. Физика и метод — разные параметры контрольной точки.

Схема JSON 5 хранит `settings.physics` и согласованный идентификатор
`model`, например `eih-1pn-dop853`. Схемы 1–4 читаются автоматически с
прежней ньютоновской физикой; миграция не меняет исходный JSON.
История старого опыта не переобозначается релятивистской при загрузке.

Численные переменные DOP853 используют вычтенные начальные положение и
постоянную скорость центра масс. При вычислении 1PN-сил восстанавливаются
скорости сохранённой инерциальной системы. Иначе перезапуск контрольной
точки мог бы изменить закон сил. Галилеевы преобразования скоростей не
являются точной симметрией 1PN; перенос положения и поворот её сохраняют.

## Диагностика

Для 1PN вычисляются энергия, канонический импульс и угловой момент из
EIH-лагранжиана по теореме Нётер. Постоянная энергия покоя Σmc² исключена.
К ньютоновской энергии добавляются члены:

```text
E₁ = (1/c²) [3/8 Σᵢ mᵢ vᵢ⁴ + 1/2 Σᵢ mᵢ Uᵢ²
     + G/4 Σᵢ≠ⱼ (mᵢmⱼ/rᵢⱼ)
       (3vᵢ² + 3vⱼ² - 7vᵢ·vⱼ - (nᵢⱼ·vᵢ)(nᵢⱼ·vⱼ))]
```

Их сохранение ограничено порядком модели: остаток содержит отброшенные
члены O(c⁻⁴), ошибки интегрирования и округления. GUI подписывает это на
графике, CLI — в `conservation_scope`. Сумма mv не выдаётся за импульс 1PN.
Отображаемый центр масс — описательная ньютоновская величина.

## Как включить

В GUI выбери `solar-system`, `python`, `dop853`, физику `eih-1pn` и нажми
«Новый сценарий». Физику начавшегося опыта можно сменить после сброса или
созданием нового сценария: это не смешивает разные модели в одном графике.

```powershell
.\.venv\Scripts\python.exe -B -m solar_simulator new solar-system pn.json --physics eih-1pn
.\.venv\Scripts\python.exe -B -m solar_simulator run pn.json year.json --steps 8766
.\.venv\Scripts\python.exe -B -m solar_simulator inspect year.json
.\.venv\Scripts\python.exe -B scripts/assess_relativity.py
```

В переносимой папке используй `runtime\python.exe`. Сеть для расчётов не
нужна: исходные векторы и GM включены в пакет.

## Независимые проверки

- Произвольные массы: ускорения сравниваются со скалярной EIH-формулой.
- Три тела: независимое дифференцирование опубликованного лагранжиана
  проверяет поправку ускорения, включая тройные потенциальные члены.
- Равные массы: аналитическая относительная двухтельная формула 1PN.
- Ньютоновский предел, перенос, поворот, обращение скоростей.
- Сохранение/продолжение в системе с большим общим движением.
- Изолированный Солнце—Меркурий: перицентры находятся по нулю r·v,
  а не по времени ньютоновского периода. Формула контроля:
  Δω = 6πG(M+m)/(c²a(1-e²)); a=0.38709893 AU, e=0.20563.
  [Вывод и величина эффекта](https://sites.science.oregonstate.edu/physics/coursewikis/GGR/book/ggr/mercury.html).
- Реальные девять тел: независимый RK45 в безразмерных единицах,
  отдельная скалярная реализация сил и три допуска проверяют численное
  согласование. Сравнение с JPL DE441 проводится отдельно на 13 эпохах.

У Земля—Луна отклонение выросло. Это показывает, что добавление верной
поправки не обязательно уменьшает суммарную ошибку неполной модели.
Причина оставшегося расхождения требует отдельной проверки: Луна ещё не
разрешена отдельным телом; также отсутствуют астероиды и несферичность.
Не приписываем весь остаток одному эффекту без измерений.

Согласование производственного DOP853 с независимым RK45 — максимум
1.497 м; изменение эталона между последними допусками — 1.512 м.
Это согласование на уровне нескольких метров, не доказанный предел
ошибки. Измеренная прецессия изолированной пары: 42.980530″/столетие;
аналитическое ожидание: 42.980471″/столетие, относительное отличие 1.38e-6.
Числа получены за пять оборотов; это экстраполяция скорости прецессии,
не интегрирование всего столетия. Ньютоновская контрольная прецессия
около 0.000115″/столетие — остаток численного определения события.

Энергия EIH: максимальный относительный остаток 1.86e-15; угловой момент:
7.91e-16 на этих эпохах. Эти значения не ограничивают ошибку координат.
Машиночитаемый отчёт: [relativity-validation.json](relativity-validation.json).
Согласование решений не доказывает полного воспроизведения DE441.
