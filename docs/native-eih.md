# Рабочие силы Newton/EIH 1PN на Rust

Этот отчёт фиксирует перенос сил и контрольные системы этапа 40.
Полный рабочий каталог позднее подключён и проверен отдельно:
[354 тела, все 343 астероида и годовой контроль](asteroids-catalog.md).

Проверено 10 октября 2026 года. Рабочий `solar_native.point_acceleration`
рассчитывает общие взаимные силы любых точечных тел: Newton либо EIH 1PN
в гармонических координатах. Массы и массивы передаются через PyO3;
геометрия пар переиспользуется, суммы векторов компенсируются по Kahan.
Все тела участвуют в поле, потенциалах и ньютоновских ускорениях источников.

SciPy DOP853 выбирает шаг и управляет допусками. Python сохраняет относительные
переменные пары, добавляет J2/C22 и работу заданных осей. EIH использует скорости
исходной инерциальной системы, включая вычтенный из переменных постоянный дрейф.
Таким образом, Rust ускоряет силы той же модели; физические эффекты от переноса
формул не появляются. Полный перенос интегратора не объявляется выполненным.

## Независимая проверка

Случайные системы из 2, 3, 27 и 354 тел сверены с Python и отдельной
скалярной Rust-формулой разработчика. Усиленная 1PN-поправка сверяется отдельно
от ньютоновского поля, чтобы большая основная сила не скрыла ошибку поправки.
Проверены оба порядка относительной пары, исходный инерциальный дрейф,
сингулярности/слабое поле, потоковые вызовы, CLI, Tk и продолжение checkpoint.

Для орбит контроль использует независимые переменные AU/year, interleaved
шесть-векторы, RK45, аналитические поля квадруполей в главных осях и отдельную
скалярную EIH. Это не рабочее native-ядро. Два уровня RK45:
`rtol=1e-13, max_step=1800 s` и `rtol=3e-14, max_step=900 s`.

| Система/интервал | Rust ↔ Python, максимум всех тел, м | Rust ↔ RK45, всех тел, м | Rust ↔ RK45, Луна относительно Земли, м | Чувствительность допусков Rust, всех тел, м |
|---|---:|---:|---:|---:|
| 27 тел, 365.25 суток, 45 эпох | 0.00963043 | 0.0522552 | 0.0235044 | 0.0166021 |
| 354 тела, одни сутки, 4 эпохи | 0.0039064 | 0.00390732 | 3.14568e-05 | 0.00195503 |

Сходимость двух независимых уровней за год: все тела
**0.0551158 м**,
Луна относительно Земли **0.00315091 м**.
Максимальный относительный остаток энергетического бюджета Rust с вычетом работы
заданных осей: **4.47048e-15** за год.
Остаток содержит также усечение совместной физической модели EIH + квадруполи.
Все цифры относятся к контрольным снимкам, не к гарантированной непрерывной границе ошибки.

## Скорость на этой машине

| Набор | Python force callback, мс | Rust callback с адаптером/копиями, мс | Ускорение callback | Ускорение всего проверенного интервала |
|---|---:|---:|---:|---:|
| 27 тел | 0.2022 | 0.0283 | 7.15× | 1.2× |
| 354 тела | 28.26 | 2.736 | 10.3× | 5.74× |

Callback — медиана пяти пакетов по 20 вызовов; время всего интервала — один
замер для каждого варианта, включая диагностику снимков. Эти результаты не
обещают фиксированного ускорения на другом процессоре или при иных условиях.
[Все измерения, хеши исходников и критерии](native-eih-validation.json).

## Запуск

```powershell
.\.venv\Scripts\python.exe -B scripts/build_native.py
.\.venv\Scripts\python.exe -B -m solar_simulator new solar-system-asteroids-full native.json --backend rust --physics eih-1pn --figures sun-earth-moon-q2 --relative-pair Earth Moon --rtol 3e-14 --position-atol 1e-5 --velocity-atol 1e-11
.\.venv\Scripts\python.exe -B -m solar_simulator run native.json final.json --steps 24
.\.venv\Scripts\python.exe -B scripts/assess_native_eih.py
```

В GUI выберите `rust`, `dop853`, `eih-1pn` и нужные фигуры/пару.
В CLI параметры 1PN/фигуры/пары выбирают DOP853 автоматически.
Если модуль отсутствует либо старый wheel не содержит новый API, выводится
команда пересборки; скрытого перехода на Python нет. Сохранения остаются схемы 8.
В переносимой сборке готовый профиль:
`scenarios/solar-system-asteroids-full-rust-1pn-solar-q2-relative.json`.

## Границы результата

Численное совпадение решений одной модели не равно совпадению с JPL.
Прежние [годовые физические остатки 27 тел](asteroids-full.md) сохраняют смысл:
порт не добавляет 327 недостающих астероидов, Койпер, кольцо, приливы,
самостоятельное вращение или более высокие порядки релятивистской модели.
354 тела в этом отчёте — пробный набор разработчика из
[проверенного начального каталога](asteroids-343.md), проверенный на одних
сутках. Он не объявлен годовым рабочим сценарием. Будущие JPL-векторы не входят
в интеграцию; используются только начальные состояния и заданная ориентация.
