# Квалификация уже реализованных EIH/J2 профилей

14 октября 2026, изменение 121. Протокол задан до запусков. Новые силы,
параметры, интеграторы или подгонка начальной орбиты не вводятся.

## Контролируемое сравнение

Одинаковые исходные Sun/Mercury/Venus/Earth/Moon/Mars/Jupiter/Saturn/Uranus/
Neptune: закреплённый solar-system-moon JD2461321.5 TDB, Ecliptic J2000,
SSB, SI; GM Earth+Moon не дублирует EMB. Год31557600с,45 закреплённых эпох
для Earth/Moon,13 для остальных JPL-векторов. JPL-данные используются только
при сравнении после свободного расчёта. Начальные условия не переоцениваются.

Профили заранее: Newton; EIH; EIH+фиксированная SolarJ2;
EIH+фиксированные SolarJ2/EarthJ2. Используются опубликованные/закреплённые
коэффициенты и оси существующих профилей; заданная во времени MoonQ2
не вводится в основной список. Фиксированные оси не означают рассчитанное вращение.

DOP853/per-body/Earth–Moon relativepair, rtol1e-13, position_atol1e-3м,
velocity_atol1e-9м/с; контроль rtol3e-14. Python/Rust силы сравниваются
отдельно с независимым RK45. Независимая сторона использует иной порядок
переменных/пар и безразмерные AU/year, отдельно кодирует EMB+Moon−Earth.
Scalar EIH oracle из scripts/validation/eih_scalar.rs не является runtime
solar_core; FixedJ2 reference использует поле в осях тела, не runtime тензор.

Reference: RK45 два уровня rtol1e-13/maxstep1800с и3e-14/900с,
atol1e-17. Пределы сходимости: все тела<1м, Moonrelative<0.1м.
Численные критерии каждого профиля/ядра: любое тело<10м/1e-4м/с,
Moonrelative<0.1м/1e-5м/с. При неподходящем reference/профиле сохранить отказ,
не заменять модель/порог/неудобное тело по результату. Дополнительно
показать чувствительность runtime rtol, Python/Rust и стоимость.

Для Newton/EIH без фигур — подходящие энергия/NoetherE/P/J;
для fixedJ2 — энергия включает постоянный внешний потенциал, оси получают
неучтённый в орбитальном J обратный момент, поэтому критерий сохранения
орбитального J не задаётся. Комбинация EIH+ньютоновская J2 не содержит
смешанных 1PN-членов фигуры; баланс энергии также ограничен усечённым порядком.
Диагностический предел дрейфа энергии1e-10; для профилей без фигур J1e-10.
Импульс фиксировать как Noether или Newton по модели, без обещания полной ОТО.

## Физические цели и область утверждения

До запуска предложен кандидат: каждый из10тел<10км максимум остатка JPL,
Moon−Earth<1км за год на заданной сетке. Пользователь разрешил проверку этих
предварительных целей и сохранение всех неуспехов до запуска расчётов.
В отчёте кандидат проверяется отдельным флагом; отказ не является разрешением
увеличить пороги, выключить тело или подогнать орбиту. Это инженерный масштаб
первой демонстрации, не стандарт навигационной точности/не неопределённость JPL.
Не превращать разрешение проверить цели в заявление достигнутой точности. Даже при успешном результате
нет гарантии между45/13эпохами, на другом горизонте или в произвольной системе.

Остатки могут включать отсутствующие астероиды, спутники, высшие гармоники,
приливы, ориентацию, физические параметры и отличия полноты модели.
Нельзя отнести весь остаток к одному эффекту без контролируемой разности.
Прежние данные и ошибки кольца420/528 сохраняются, кольцо в этот блок не добавляется.
