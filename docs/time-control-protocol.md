# Протокол управления временем — изменение123

Критерии записаны до реализации и измерений, 14 октября2026.
Новый контроллер вызывает существующий `advance`; уравнения и физические
данные не меняются. Время — конечное неотрицательное float64 число секунд
от начала опыта (для JPL исходная эпоха TDB сохраняется в origin).

## Контракт

- Цель не меньше текущего времени, равная цель ничего не интегрирует.
- Пакет содержит не более2000 номинальных шагов/интервалов; пользователь
  задаёт меньший предел. Расчёт не перескакивает цель, достигнутая цель
  хранится точно как введённое число float64. Неразрешимые временные
  интервалы отклоняются, состояние не переименовывается в нужную эпоху.
- Verlet: прежний dt для полных шагов; единственный конечный шаг может
  быть короче. Settings возвращаются неизменными. В конечном интервале
  меняется сетка, поэтому побитовое совпадение с другой сеткой не обещается.
- DOP853: ограничивается длительность пакета, прежние rtol/atol, физика,
  фигуры и относительная пара сохраняются. dt не является внутренним шагом.
  Перезапуски решателя при разных пакетах могут менять накопленную ошибку.
- Контакт stop сохраняет фактическое время события до цели; bounce/merge
  продолжают по прежней модели. Вращение и заданные ориентации используют
  существующее абсолютное время, включая ограничения срока модели.
- GUI считает в worker, Tk обслуживает ограниченные пакеты. Пауза завершает
  уже отправленный пакет. После загрузки JSON цель вводится заново;
  сохраняется физическое состояние, а не намерение продолжать автоматически.
  Возврат назад пока через загрузку контрольной точки/сброс и новый расчёт.

## Независимая проверка и критерии

Ньютоновская наклонённая двойная система из стенда120: массы4e30/7e29кг,
G=6.67430e-11 SI, апоцентр1.5e11м, e=0.425531915, период12108756.587с.
Аналитический Kepler — независимая бисекция, балансы — отдельные суммы.
Цель0.731234 периода, не кратная dt. До: явная серия advance с конечным
коротким шагом. После: контроллер, пределы пакетов1/7/64, оба ядра.

- DOP853: ошибка относительного положения<10м, скорости<1e-5м/с,
  относительные дрейфы E/L<1e-10; расхождение разбиений<1м.
- Verlet:1024/2048/4096 шагов на период, отношение конечных ошибок3.8–4.2.
  Полная сетка контроллера совпадает с явным advance+конечным коротким шагом.
- До/после при одном разбиении совпадают, исходный опыт неизменен.
- JSON pause/resume при одинаковой последовательности пакетов совпадает
  с непрерывным выполнением этой последовательности; все Settings прежние.
- Контакт до цели, отказ обратного/NaN/Infinity/bool/неразрешимого времени,
  ошибочный ввод GUI до применения настроек, пауза во время worker, повторное
  продолжение, загрузка/сброс и старый обычный запуск проверяются отдельно.
- Реальные Tk окна прежних размеров и полный регрессионный набор.

Записываются время выполнения, ошибки и неуспехи. Это проверка временного
контроллера, не новая квалификация физической точности Солнечной системы.
Годовые показатели121 остаются ограничены прежними эпохами/исходными данными;
не переносятся автоматически на другое разбиение или пользовательскую систему.
