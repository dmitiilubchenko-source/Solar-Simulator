Те же десять тел и float64 IC из `solar-sandbox-strict-checkpoint.json`,
SHA256 `65cd1b3eb5c815df11cd45a7106d8cc4ecb5828d10761715831aaf2571b3548d`.
Sun,Mercury,Venus,Earth,Moon,Mars,Jupiter,Saturn,Uranus,Neptune.
Массы внешних планет — исходные барицентры систем, без новых спутников.
SI, SSB, Ecliptic J2000, JD2461321.5 TDB, DE441 provenance;
физические уравнения интегрируются в секундах от t0 опыта.
125прежних `year_times` из `continuous-integration-reference.npz`,
SHA256 `e1cb054f6d5f2ca9b0e983e7f824fcd3e03e99c471266d8bfc3200bd74d67b55`,
0–31557600с. Из этого NPZ используются только времена, не траектории.

Оба кандидата: полная взаимная order-reduced EIH 1PN, гармонические
координаты, положительные точечные массы, G контракта Solar,
c=299792458м/с, исходные инерциальные скорости. Ньютоновские ускорения
источников внутри1PN, без итеративного включения неполных2PN-членов.
J2/прочие фигуры отключены явно в обоих методах. Без вращения/излучения/
приливов/контактов/смягчения. U/c²,v²/c²<1e-4 — область применения,
не гарантия физической точности. Нельзя использовать Newton/J2/JPL-oracle.

## Независимый эталон и проверки его реализации

RK45 с interleaved состояниями в AU/year, независимым EMB+Moon−Earth
отображением из проверенного ньютоновского стенда. Это только изменение
численных переменных; закон силы — полный EIH. Скорости для силы
восстановлены в исходной системе. Прямая rho используется в Earth–Moon
геометрии без повторного вычитания абсолютных координат.

ScalarEIH из `assess_relativity.py` вычисляется полной матрицей NumPy,
с направлением source→target. Никаких вызовов runtime Python/Rust force
или координатного класса. До интегрирования: скалярная сверка на2/3/10телах,
сравнение отдельно PN-поправки при усилении через исследовательское c,
сверка с native, единицы AU/year/day, оба порядка пары, предел Newton,
сингулярности/слабое поле. Пороги force3e-14 по норме, выделенной усиленной
PN3e-9 относительно максимальной нормы поправки. Это изменение вычисления
эталона, не оптимизация физического ядра.

Три уровня (rtol,maxstep): (1e-13,1800с),(3e-14,900с),(3e-14,450с),
atol1e-17AU/1e-17AU-year. Четвёртый —450с/AU-day с физически теми же
atol. RK45 использует quartic interpolation на выходной сетке;
проверяются все125эпох. Последние два уровня и сменаclock:
каждое тело <1м/<1e-6м/с; Moon−Earth <0.01м/<1e-7м/с.
Начальный roundtrip <0.002м/<1e-8м/с, пары <0.0001м; первый снимок
эталона не подменять исходным. Перед годом пилот30суток: подмножество
исходной сетки плюс точный конец30DAY. Сохранять все отказы и уровни.
Принятие эталона эмпирическое; не строгая граница ошибки на всём интервале.

## Кандидаты и критерии

DOP853: существующий ContinuousRun/native/per-body/relativeEarthMoon,
rtol3e-14, dt3600с/packet20. Baselineatol0.001м/1e-9м/с;
отдельная чувствительность1e-7м/1e-13м/с, без смены default.
IAS15: прежний researchадаптер177–179/REBOUND5.2.2, epsilon1e-9/1e-11,
PRS23/min_dt0/initialdt18с, gravitynone+полноеnativeEIH overwrite,
velocityflag1, directCartesianSI, без COM-переноса/парного forceoverride.
Существующее поле relative_pair настройки не меняет представление IAS15;
разница представлений методов указана явно. Callbacklatch+stop+rethrow.
Те же499точных границ пакетов, noovershoot, контроллер сохраняется.

Относительно принятого EIH-эталона: каждое тело <10м/<1e-4м/с;
Moon−Earth <0.1м/<1e-5м/с. Независимый NoetherE/P/J drift<1e-10,
из скалярного EIH action через complex-step производные, как в177–179.
E нормируется на |E0|, P на Σm|v0|, J на |J0|. Оговорка O(c^-4).
Начальная сверка независимых E/P/J с runtime <5e-14 в этих масштабах.
Ньютоновские инварианты не критерии EIH. Не подбирать параметры по JPL.

Сохранять per-body и pair ошибки всех вариантов. Повторы и3timingruns
побитны, пакетные границы равны; вход/source/library/actualnativepyd SHA
до/после неизменны. Длинные вычисляемые исходники не редактировать.
Стоимость: прогрев+3чередующихся полных траектории, включая физический
callback/FFI/setup/снятие125состояний; вне таймера reference/Noether/
файлы/хеширование. steps_done не RHS/acceptedcount. Ни16–17раз для
Newton/Cgravity, ни1.55–2.69замедление модельных задач не переносить сюда.
