# Земля и Луна отдельными телами

Сценарий `solar-system-moon` содержит десять точечных тел: Солнце,
Меркурий, Венеру, Землю, Луну, Марс, Юпитер, Сатурн, Уран и Нептун.
Кроме Земли и Луны, планеты представлены точечными планетными системами.
Прежний `solar-system` с общим Earth-Moon сохранён для сравнения.

## Данные и согласованность

Начальная эпоха та же: 2026-10-08 00:00 TDB, JD 2461321.5; JPL DE441,
эклиптика J2000, геометрические координаты относительно барицентра
Солнечной системы, единицы SI. Земля — ID 399, Луна — 301, контрольный
Earth-Moon — 3. Используется тот же сохранённый официальный GM kernel.
Настройки запросов описаны в [официальном API JPL](https://ssd-api.jpl.nasa.gov/doc/horizons.html).

Импортёр проверяет GM(399)+GM(301)=GM(3) с относительным допуском 1e-14.
GM — произведение гравитационной постоянной на массу. В модели массы
получаются как GM/G, поэтому суммарная масса системы сохраняется.
Остальные тела получают точно прежние массы, положения и скорости.

По независимому ответу JPL для ID 3 проверяется взвешенное положение
и скорость пары на каждой из 45 эпох. Покомпонентные допуски:
0.01 м и 1e-8 м/с. Вес Луны = GM(Moon)/GM(Earth-Moon).
Проверки защищают от использования массы всей системы вместо массы
Земли и от добавления Луны одновременно с общим Earth-Moon.

Снимок: `solar-system-moon-20261008.json`, SHA-256:
`d58227299b10b217246aa5c63f33da51b0fd331b5c7a75bee400d577d6d1f702`.
[Контрольные векторы](solar-system-moon-reference.json) содержат ежедневные
точки первых 32 суток и прежние 13 годовых точек — 45 разных эпох.
Есть SHA ответов, URL запросов и привязка к прежнему снимку/эталону.
Начальные состояния включены в пакет и работают без сети.

## Запуск

В GUI выбери `solar-system-moon`, `python`, `dop853`, физику `eih-1pn`
и нажми «Новый сценарий». Для просмотра лунной орбиты выбери
«Относительно → Тело: Earth», затем приблизь график: расстояние до Луны
намного меньше размеров планетных орбит. Проекции остаются XY/XZ/YZ.
Выбор относительного вида меняет отображение; взаимодействия считаются
для всей системы в сохранённой инерциальной системе координат.

```powershell
.\.venv\Scripts\python.exe -B -m solar_simulator new solar-system-moon moon.json --physics eih-1pn
.\.venv\Scripts\python.exe -B -m solar_simulator run moon.json month.json --steps 768
.\.venv\Scripts\python.exe -B -m solar_simulator run moon.json year.json --steps 8766
.\.venv\Scripts\python.exe -B -m solar_simulator gui month.json
.\.venv\Scripts\python.exe -B scripts/assess_resolved_moon.py
```

dt по умолчанию 3600 с: 768 интервалов = 32 суток, 8766 = юлианский год.
CLI и GUI сохраняют десять тел, физику и происхождение в существующей
схеме 5. Без `--physics` CLI выбирает newtonian. Newtonian/Verlet/Rust
также доступен, но фиксированный шаг нужно проверять на лунной орбите.

Загрузка официальных данных или воспроизведение из локального кеша:

```powershell
.\.venv\Scripts\python.exe -B scripts/fetch_resolved_moon.py
.\.venv\Scripts\python.exe -B scripts/fetch_resolved_moon.py --cached
```

Импортёр использует прежний закреплённый GM kernel из `.tools/jpl-20261008`.
Запросы выполняются последовательно; TLS-проверка сохранена. Пользователю
готовой переносимой сборки импортёр и кеш не нужны.

## Результат разделения системы

На тех же 13 годовых эпохах, с одинаковыми исходными данными остальных
тел и одинаковой EIH 1PN, максимальное отклонение от JPL:

| Величина | Общий Earth-Moon (9 тел) | Отдельные Earth и Moon (10 тел) |
|---|---:|---:|
| Барицентр Земля—Луна | 97598 м | 165 м |
| Mercury | 313 м | 312 м |
| Venus | 229 м | 233 м |
| Mars | 572 м | 572 м |

Для других систем изменения невелики. Частота выдачи результатов влияет
на перезапуски адаптивного интегратора, поэтому метровые отличия от
исторического отчёта [1PN](relativity.md) ожидаемы в пределах измеренного
численного согласования. Разделение объясняет большую часть прежнего
расхождения Earth-Moon на этом опыте.

По всем 45 эпохам нового сценария, EIH 1PN:

| Величина | Максимальное отклонение от JPL |
|---|---:|
| Земля в общей системе координат | 392 м |
| Луна в общей системе координат | 25323 м |
| Барицентр Земля—Луна | 165 м |
| Луна относительно Земли | 25612 м |
| Луна относительно Земли за первые 32 суток | 2011 м |

В Newtonian для десяти тел: барицентр около 55730 м, относительная Луна
около 21718 м за год. Поэтому улучшение общего центра не означает
одинаковое улучшение всех величин. Эффекты могут частично компенсироваться
в неполной модели; оставшийся лунный остаток требует отдельного изучения.

## Численная проверка и границы

Независимый эталон использует RK45 в безразмерных единицах и отдельную
скалярную EIH-формулу; выполнены три допуска. Изменение эталона между
последними допусками — максимум 1.773 м. Согласование с производственным
DOP853: Земля 0.092 м, Луна 7.493 м, остальные тела до 0.302 м.
Изменение производственного расчёта при rtol=1e-13→3e-14 — до 2.087 м.
Пороги согласования <10 м и <1e-4 м/с проходят для всех десяти тел.
Это проверка на снимках, а не гарантированный предел ошибки между ними.

Оставшиеся десятки километров лунного отклонения существенно превышают
измеренное численное согласование. Земля и Луна пока сферические точечные
массы: нет несферичности, вращательной динамики, приливов/диссипации,
астероидов и отдельно разрешённых спутников других планет. Нельзя
объявлять весь остаток влиянием одного фактора без контрольного расчёта.
Секулярное приливное удаление Луны в этот этап не включалось.

[Полный машиночитаемый отчёт](moon-validation.json).
Следующая проверка — измерить вклад несферичности Земли и Луны с
обоснованными параметрами и ориентацией, сохраняя сравнение с JPL.
