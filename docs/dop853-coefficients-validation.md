# Коэффициенты DOP853: перенос точный, округление измерено

21 октября2026,346. [Протокол до результатов](dop853-coefficients-protocol.md),
[все200×2 точных невязки и литералы](dop853-coefficients-validation.json),
[программа](../scripts/audit_dop853_coefficients.py),
[независимые проверки](../tests/test_dop853_coefficients.py).

Все168 A/B/C Rust побитно соответствуют округлённым значениям закреплённого
исходника SciPy1.18.1. Ошибки переноса этой части таблицы не обнаружено.
E3/E5/контроллер/интерполяция здесь не проверялись.

По [условиям автономной векторной задачи](https://arxiv.org/abs/2112.01608v1),
раздел2,(6)–(8), точная Fraction-арифметика дала:

| Величина | Exact binary64 таблица | Exact десятичные литералы источника |
|---|---:|---:|
| sum(B)−1 | +6.9388939e-17 | +6.6e-30 |
| max abs(sum(A_i)−C_i) | 1.7971735e-15 | 5.8e-29 |
| max abs(tree residual), порядок2 | 4.5759932e-16 | 9.2582124e-30 |
| max abs(tree residual), порядок4 | 6.4543791e-16 | 2.4439521e-29 |
| max abs(tree residual), порядок8 | 7.1146407e-16 | 2.6833308e-29 |

Это безразмерные невязки полиномиальных условий; они не равны ошибке орбиты
в метрах. Числа показывают влияние округления таблицы, но не доказывают,
что оно объясняет FAIL335 либо немонотонность339. Даже десятичные литералы
конечны: все200 невязок ненулевые; строгий порядок8 идеального метода и
поведение при произвольно малом h этим анализом не установлены.

Программа проверена на рациональных Euler/midpoint/RK4, всех восьми явных
условиях порядков1…4 для произвольной таблицы, независимой линейной
рекурсии до8 и числе деревьев1,1,2,4,9,20,48,115. Проверены также SHA-отказ,
запрет исполнения источника, дубликаты/неявность и сохранность старого отчёта.
Первый прогон:5testsPASS2.61с; сам аудит0.394с. Сеть для повтора не нужна:

```powershell
.venv/Scripts/python.exe -X utf8 -B -m scripts.audit_dop853_coefficients --output .tools/new-coefficient-audit/result.json
```

Нужны ровно закреплённые байты исходника, по умолчанию из установленной SciPy;
иная версия отклоняется поSHA. Код не загружает и не исполняет исходный файл.
Расчёт детерминированный, walltime/GitHEAD в новом receipt могут отличаться.
Точные значения таблицы и всех невязок доступны в публичном JSON.

Raw Hairer недоступен: прямые запросы и повтор web вернули503. Первое web-чтение
подтвердило описание8(5,3) и авторов, но rawSHA и полная сверка литералов с ним
не получены. Источником фактической исследуемой таблицы остаётся pinnedSciPy.
Математическая первичная публикация Butcher/Podhaisky доступна через arXiv.
