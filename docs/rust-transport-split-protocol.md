# Упорядоченное разделение перенесённых вкладов: протокол350

21 октября2026, до результатов350. Запуск допустим только после завершённого
349 с source/inputSHA/precision/endpoint checks. Цель — разделить перенос
ошибки одного binary-table высокоточного RK-шага и остаток native trial.
Runtime/новые допуски/новый solver не входят в опыт.

Все9 случаев и4473 accepted шага прежние. Native old/trial, shadow80 и
local analytic flow100 — из public348; z_i и exact clocks — из public349;
prepared final oracle/GM — из338. Старые rawtrace/абсолютные пути не нужны.
Проверить SHA/все индексы/битовые состояния/elapsed, не отбирать шаги или эпохи.

Обозначить r_i=shadow80 локальный RK-результат из того же native old y_i.
После шага осталось d_i=T−s_(i+1). Вычислить
w_i=Phi_(d_i)(r_i), затем два векторных вклада:

```
RK_i     = w_i − z_i
native_i = z_(i+1) − w_i
```

Первый включает дискретизацию метода и конечные binary64-коэффициенты;
второй — совокупность native RK/RHS/GM-представления относительно shadow.
Это один фиксированный порядок нелинейного разложения на native-траектории.
Он не является уникальной причинной атрибуцией и не равен сравнению двух
свободно эволюционирующих орбит. Не называть его выделением одной операции.

Вычислить w70/w100, сравнение<1e-20м/<1e-26мс. Для каждого шага отдельно
проверить semigroup100: Phi_(d_i)(local_flow100_i) согласуется с z_i100
в тех же пределах. Это проверка композиции на всех4473 шагах, а не только
один пример. z_N имеет remaining0; new RK input80 содержит лишь ранее
измеренный локальный остаток50/80, не искусственную поправку орбиты.

Разности и суммы сохранять с проверкой exactFraction. На каждом шаге
RK_i+native_i должен точно равняться старому c_i349; общие суммы —
total349. Это тождества разложения, не новый accuracyPASS. Сохранить оба
signed вектора/нормы/параллельные и ортогональные проекции на прежнюю
prepared final velocity; показывать и компенсацию, и усиливающиеся вклады.
Не складывать нормы компонент как равенство модулю конечной ошибки.

Независимые проверки: искусственные точно известные z/w при большой
компенсации и обратных знаках, потеря/сдвиг индексов, corrupted receipt/NPZ,
семигруппа круга/эллипса из349, сохранность outputs. Полный public replay
всех4473 разложений безraw/net, source/inputSHA до/после и стоимость отдельно.
