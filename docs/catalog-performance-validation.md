## Где расходуется время

Один прогрев и3повтора; медианы. Пакет20×3600с =20часов моделирования.
Сериализация и проверки повторных состояний выполняются вне таймера.

| Стенд | Только интегрирование, мс | Отчёт отдельно, мс | Интегрирование + отчёт, мс |
|---|---:|---:|---:|
| 10 тел, EIH + заданные Q2, Rust | 180.49 | 2.64 | 177.87 |
| 27 тел, EIH + заданные Q2, Rust | 203.62 | 3.58 | 212.53 |
| 354 тела, готовый EIH + заданные Q2, Rust | 824.34 | 121.61 | 946.88 |
| 354 тела, Newtonian, Python | 1307.16 | 90.16 | 1391.82 |
| 354 тела, Newtonian, Rust | 165.09 | 81.77 | 245.34 |

Три измерения не дают статистического интервала; небольшие различия могут
быть шумом, как видно в10body строке. Отдельные медианы не складываются
в точное разложение общего времени.10/27 строки имеют те же строгие
допуски и заданные Q2, что354, для сравнения масштаба; это другие профили,
чем проверенная десяти-тельная демонстрация с фиксированными Sun/Earth J2.

Для354EIH адаптер одной силы занимает2.453мс, native с уже готовыми
списками2.299мс, отдельные Python-преобразования0.133мс. Внутри native
замера остаются PyO3 conversions, allocation и сама сила: чистое FFI
не выделено. Поэтому нельзя приписывать всю разность преобразованиям.
За пакет209RHS: заметная работа уже выполняется внутри Rust, где
62 481 парная связь. Простой перенос оставшегося интерфейса на Rust
не устраняет эту работу. EIH и заданные ориентации дороже Newtonian;
заменять модель ради более красивого времени нельзя.

Контроль Newtonian backend на72000с: maximum per-body difference1.382мм
(Pluto-System), relative Earth–Moon0.061мм. Независимые скалярные
math.dist/math.fsum инварианты: relative E≤1.863e-16, L≤1.582e-16,
scaled P drift≤7.350e-17. Все заранее заданные критерии прошли.
Это проверка backend/инвариантов, не независимая сертификация траекторий
354тел и не измерение их истинной физической точности.
