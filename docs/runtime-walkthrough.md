# Один полный шаг Solar Simulator

Эта карта предназначена для изучения после закрепления рабочей версии.
Основные библиотеки перечислены в pyproject.toml; ядро пока SciPy DOP853/
Verlet и собственные силы, REBOUND/Tudat не подключены.

1. Окно держит текущий Experiment: тела, настройки, происхождение, время,
   история контактов и начальные/текущие состояния вращения. Изменение
   вида/проекции влияет только на график.
2. Кнопка «Один шаг» применяет допустимые настройки и отправляет advance
   в ThreadPoolExecutor. Tk продолжает обслуживать события в главном потоке.
3. advance выбирает модель и интегратор. Для точечных тел DOP853 решает
   систему положений/скоростей; для одной жёсткой фигуры добавлены q[4]/S[3].
   Силы рассчитываются Python/NumPy или выбранным Rust-ядром.
4. Для Verlet dt — физический шаг, выполняемый steps раз. Для DOP853
   advance задаёт интервал dt × steps, а адаптивный решатель самостоятельно
   принимает/отклоняет внутренние шаги по оценке ошибки. В конце пакета
   приложение получает состояние для снимка. Новый пакет перезапускает
   решатель; изменение разбиения может немного изменить численный результат.
   Для контактов работает отдельный путь с Verlet.
   В режиме цели advance_towards ограничивает последний пакет. У Verlet
   сокращается конечный шаг, у DOP853 длительность интервала; физические
   Settings возвращаются прежними. [Контракт и измерения](time-control-validation.md).
5. После завершения Future цикл _poll принимает новый Experiment, записывает
   снимок и диагностику и рисует графики. Пауза дожидается отправленного
   пакета; она не обрывает физический шаг. Ошибка оставляет последний результат.
6. Сохранение JSON хранит физическое состояние/исходные условия и настройки.
   Оно не хранит графический след: после загрузки начинается новая история
   снимков. Для динамической фигуры схема10 сохраняет q/S/инерцию/допуски.

Практический разбор: поставить точки остановки перед отправкой advance и
при получении его результата, сравнить Experiment до/после, затем отдельно
проследить внутренний DOP853. Начать с двух тел, после этого перейти к Луне.
Короткий статус не является измерением точности. Тесты реализации, аналитика,
сходимость и отличие модели от эфемерид отвечают на разные вопросы.
