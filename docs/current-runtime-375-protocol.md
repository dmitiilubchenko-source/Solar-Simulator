Пользовательские системы: шесть старых сценариев × Python/Rust; прежние
Kepler/RK45/free-motion критерии, баланс E/P/L, неизменность parent,
сохранение/загрузка/продолжение на диске и запись фактических выходов.
Те же accepted032 исходники выполняются в изолированных процессах в сегодняшнем
окружении; полное историческое окружение не реконструируется. Побитность
фиксируется по результатам; любое различие требует анализа, а не ярлыка ошибки.

Новый отчёт и массивы получают уникальные имена. В ходе jobs исходники,
данные и native неизменны. Новые source/data/environment/native SHA обязательны.
`check_receipts` обновляется только после достаточных фактических доказательств;
old grid FAIL и old Strict остаются неизменны. Никаких archive SHA для допуска
сегодняшнего solver. При отказах сохранить их и не делать skip/xfail.
