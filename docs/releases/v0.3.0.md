# Solar Simulator 0.3.0 — подготовленная версия

Версия подготовлена в `dev` после проверенного 0.3.0rc1. Этот документ
не означает публикации тега/GitHub Release или переноса изменений в `main`.
Конкретный ZIP принимается отдельно по результатам его проверки и SHA256.

## Подготовка поставки

Согласуются версии приложения, native-wheel, обоих Cargo-манифестов и lock-файлов.
Native-wheel выбирается по версии и ABI; более новый по mtime старый wheel
не подставляется автоматически. Метаданные Python и Rust-компонентов — 0.3.0.

Сборщик сам изолирует оба проверочных запуска: отдельные LOCALAPPDATA и
MPLCONFIGDIR во временном каталоге вне будущего ZIP, очистка внешних Python/Tcl
переменных, ограниченный PATH в Windows. Родительское окружение не меняется.
Удаляется только собственный проверочный профиль, при успехе и при ошибке;
пользовательские recovery и прежние сборки сохраняются.

Полная проверка исходников: `scripts/check_project.py --require-native`.
Настоящий ZIP проверяется после свежей распаковки с изолированными импортами,
Tcl и LOCALAPPDATA. Сквозной сценарий проходит Python/DOP853 и Rust/Verlet:
редактор единиц → ветка → запись/закрытие → восстановление/продолжение в новом
процессе → просмотр/сравнение/экспорт → CLI audit/replay полного и stopped-префикса.

## Совместимость и ограничения

Физические силы, интеграторы, начальные данные и допуски этим выпуском не меняются.
Повторяются прежние проверки доставленного runtime; новый номер не является
новым измерением физической точности. Годовые показатели относятся к исходному
10-тельному Strict-профилю и заданной сетке эпох. Изменённые системы требуют
собственной проверки. Старые неудачные численные критерии не переписываются.

Контрольные точки и записанные кадры прежних версий остаются читаемыми.
Recipe фиксирует версию и файлы окружения: строгий повтор записи 0.3.0rc1 в
0.3.0 может быть отклонён как несовместимый. Рецепт не переписывается для
искусственного подтверждения совместимости; просмотр и продолжение checkpoint
проверяются отдельно от строгого воспроизведения старого окружения.

Continuous и кольцо Койпера сохраняют экспериментальный статус. Непройденные
общие критерии, ограничения PN×J2/Noether/вращения и отсутствие приливов/3D
не устраняются сменой версии. Подробности физики — в соответствующих отчётах.
