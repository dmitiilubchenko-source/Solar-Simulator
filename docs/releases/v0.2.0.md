# Solar Simulator 0.2.0 — первый выпуск

Настольная лаборатория ньютоновской гравитации на Python и Rust.
Можно выбрать учебный сценарий, изменять начальные условия, запускать
и останавливать расчёт, исследовать траектории и сохранять контрольные точки.

В выпуск входят:

- взаимное притяжение N тел в 3D и Velocity Verlet;
- пять сценариев, проекции XY/XZ/YZ и относительный вид;
- остановка при касании, последовательные отскоки и учебное слияние сфер;
- энергия, импульс, полный угловой момент и центр масс;
- JSON-сохранение и продолжение, CLI и сравнение dt/dt2/dt4;
- переносимая Windows x64-сборка с Python/Tk и Rust-модулем.

Проверки: 247 тестов Python, 15 тестов Rust, запуск интерфейса,
продолжение через контрольную точку на обоих ядрах и распаковка
Windows-сборки в другой каталог с изолированным Python/Tcl.

Для Windows скачайте ZIP и соседний SHA256, распакуйте архив и откройте
`Solar Simulator.cmd`. Устанавливать Python или Rust для этой сборки
не требуется. Исходный проект запускается через `Запустить.cmd` после
установки зависимостей по README.

Начальные орбиты учебные, без реальных эфемерид. Нет относительности,
приливов, трения, разрушения и вращательной динамики. Одновременные и
устойчивые контакты требуют отдельной модели. Слияние сохраняет массу,
импульс и полный угловой момент, но не моделирует термодинамику планет.
Точность тесных сближений требует исследования физического шага.

Полные инструкции и ограничения — в [руководстве](../user-guide.md).
