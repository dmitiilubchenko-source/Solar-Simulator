# Solar Simulator 0.3.2 — кандидат maintenance-выпуска

Готовность исходников и конкретного ZIP подтверждается
[внешним отчётом](https://github.com/dmitiilubchenko-source/Solar-Simulator/blob/dev/docs/release-032-validation.md).
Поставку принимают по её SHA после свежей распаковки. Разработка идёт в dev;
перенос в main, тег и GitHub Release согласуются отдельно.

## Что изменилось после 0.3.1

- [Меню документации](https://github.com/dmitiilubchenko-source/Solar-Simulator/blob/dev/docs/README.md),
  короткая карта, архив законченных ревью и README рядом с компонентами.
- Короткая приёмка сгруппирована в scripts/sandbox_checks; старые команды
  и импорты сохранены. Физические реализации не копируются.
- Быстрый CI дополнительно запускает существующие проверки portable-документов
  и восстановления публичных тестовых входов.
- Python, поставляемый native и standalone core согласованы на 0.3.2.
  Прежние источники 0.3.1 и таблица истории сохранены без изменения старых SHA.

## Совместимость и границы

Форматы checkpoint, parent и полных кадров, численные пакеты и SI сохраняются.
Старые файлы можно читать и продолжать. Строгий recipe replay проверяет версию
и среду и может отклонить прежний рецепт; он не переписывается ради PASS.

Формулы сил, интеграторы, начальные данные и допуски не менялись. Новые
исследования IAS15 не внедрены в продукт. Solar_adaptive остаётся research 0.3.0,
REBOUND и исследовательские зависимости в desktop runtime не включены.
Поставка заново проверяется штатным годовым Strict-сценарием по сохранённым
JPL-входам. Его ограниченная сетка и состав не квалифицируют произвольные системы.
Standard numerical FAIL, general continuous gate, PN/Noether и вращательные
ограничения сохраняются. Кольцо Койпера экспериментально: 420 не прошло
геометрический критерий; 528 прошло свои проверки, но остатки отдельных KBO
относительно SB441 выросли. Приливы, новая физика и 3D не добавлены.

Полная source/native-приёмка, пользовательские сценарии и настоящий ZIP
должны пройти на окончательном кандидате. Пока это описание состава,
а не самостоятельное доказательство готовности.
