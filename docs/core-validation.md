# Проверка вычислительного ядра

Дата проверки: 8 октября 2026 года. Модель: ньютоновские точечные массы, SI, Velocity Verlet, без контактов.

## Что проверено

- Три орбиты Солнце–Земля: эксцентриситет 0, 0.3 и 0.6; по одному периоду.
- Для каждой: 2000, 4000 и 8000 шагов, Python и нативный Rust — всего 18 запусков.
- Независимый эталон: SciPy DOP853 решает относительное движение в безразмерных единицах, не вызывает рабочую формулу ускорения.
- Сравниваются координаты и скорости; энергия, линейный и угловой моменты; движение центра масс.
- Дополнительно: обратимость гладкого движения, существующие длительные орбитальные проверки и симметрии 3D.

## Результаты

Полная проверка после изменений: **251 Python-тест и 15 Rust-тестов**, без пропусков и ошибок. Формат Rust и ссылки документации также проверены.

Максимумы ниже взяты по 101 снимку на период и могут пропустить промежуточные пики. При 8000 шагах dt ≈ 3944.68 с. Значения округлены; оба ядра дают практически одинаковые результаты в этой задаче.

| Эксцентриситет | Ошибка координат / AU | Ошибка скорости / √(GM/AU) | Относительная ошибка энергии |
|---|---:|---:|---:|
| 0 | 1.34986e-06 | 1.29193e-06 | 9.37857e-14 |
| 0.3 | 5.10259e-06 | 8.00075e-06 | 3.35353e-07 |
| 0.6 | 8.42504e-05 | 0.000266303 | 4.56993e-06 |

Отношения ошибок координат при удвоении числа шагов: 3.99999–4.00047. Это подтверждает второй порядок на выбранных гладких задачах. Масштабированная ошибка импульса, относительная ошибка углового момента и ошибка центра масс / AU прошли порог 1e-11.

Критерии для самого мелкого шага: координаты < 5e-4 AU, скорости < 0.002 единицы скорости, энергия < 0.001. Это учебные критерии этой матрицы; они не задают точность реальных эфемерид.

На круговой орбите ошибка координат составляет около 202 км, хотя энергия сохраняется значительно лучше. Следовательно, оценка только по энергии недостаточна. Для e=0.6 ошибка составляет около 12 604 км: фиксированный шаг требует осторожности при быстром движении в перицентре.

## Производительность

Синтетические состояния с фиксированным seed, 100 шагов по 60 с; 2, 16 и 64 тела. Прогрев вне измерений; три серии длительностью не менее 50 мс, медиана времени одного пакета. В стоимость включены Python→Rust и преобразование результата. Для каждого пакета повторно используются одинаковые исходные состояния. Диагностика, контакты, сохранение и интерфейс не включены.

| Тел | Python, мс / пакет | Rust, мс / пакет | Отношение времени Python/Rust |
|---|---:|---:|---:|
| 2 | 2.913 | 0.017 | 172.1 |
| 16 | 107.492 | 0.249 | 432.3 |
| 64 | 1618.684 | 2.953 | 548.1 |

Эти числа относятся к данному компьютеру и установленной сборке. Они не обещают такое же ускорение интерфейса или любого сценария. Попарный алгоритм остаётся O(N²).

## Повторение

```powershell
.\.venv\Scripts\python.exe -B scripts/assess_core.py --output .tools/core-check.json
.\.venv\Scripts\python.exe -B scripts/check_project.py
```

Требуются зависимости разработки SciPy/pytest и собранный нативный модуль. Без Rust можно передать --python-only; такой запуск не проверяет нативное ядро. Отчёт JSON содержит пороги, результаты, версии среды и SHA-256 скрипта, Python-ядра и нативного бинарного модуля. При нарушении критериев скрипт завершается с ошибкой.

Результат измерений: [core-validation.json](core-validation.json).

## Требования следующего этапа

1. Сценарий Солнце и восемь планет должен явно задавать эпоху, шкалу времени, систему координат, единицы и источник исходных векторов.
2. Сравнение с эталоном должно использовать те же параметры GM и перечень тел. Различия физической модели отделяются от ошибки численного интегрирования.
3. Первая контрольная длительность — один год; проектная цель сравнения с решением той же модели: координаты < 100 км и скорости < 0.1 м/с для каждой планеты. Шаг подбирается по сходимости; это цель, а не уже достигнутая гарантия.
4. Для реальных эфемерид пока не обещаем эти допуски: отсутствующие Луна/астероиды, релятивистские эффекты и другие различия нужно оценить отдельно.
5. Приливное удаление Луны относится к отдельной модели вращения и диссипации. Оно не получается из текущей точечной гравитации.

Новые физические силы в этой итерации не добавлялись.
