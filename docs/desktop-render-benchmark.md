Для354тел построение ускорилось примерно в2раза. На2телах выигрыша
не наблюдалось: несколько миллисекунд дополнительной работы;3повторов
недостаточно для статистического утверждения о малой разнице.
Рисование canvas улучшилось меньше построения. Ни эти времена, ни
совпадение графиков не характеризуют физическую точность.

Вместо708Line2D для354тел используются2collections: все траектории
и все текущие маркеры. Сохранены XY/XZ/YZ, относительный вид даже при
скрытом центре, разные составы тел до/после слияния, legend и autoscale.
Все1500удержанных снимков остаются в графике. Сначала collection-only
вариант дал0.316919с построения, массивная проекция дала0.230422с;
исходные и промежуточные receipts сохранены локально.

Одна завершённая итерация GUI передаёт freshreport из записи кадра
в отрисовку, избегая повторного расчёта. Постоянного кеша состояния нет:
ручная отрисовка вычисляет новый отчёт. Короткий status берёт только
время/модель/события/потери непосредственно из текущего Experiment.
