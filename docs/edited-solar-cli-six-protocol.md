# Рабочий CLI: три годовых опыта с пакетом 6 часов

Дополнительная проверка этапа 209, объявлена до запуска CLI. Используются
ровно три дочерних старта и Settings из [годового исследования](edited-solar-year-protocol.md).
Силы, данные и допуски прежние. Проверяется пользовательский путь
input JSON → настоящий CLI → snapshots.csv / final.json / receipt.json.

Текущий GUI batch по умолчанию равен 20: при strict dt=3600 с пакет длится
72000 с (20 ч). У continuous CLI packet_steps по умолчанию также 20.
В исследовании выходные эпохи через 6 ч ограничивают пакет, поэтому
оно не проверяет пакеты по 20 ч. GUI, defaults, схема и общие флаги CLI прежние.

Из закреплённого fixture каждого случая сохранить новый input JSON
в новой папке .tools. Запустить реальный модуль в отдельном процессе:

```powershell
.venv/Scripts/python.exe -X utf8 -B -m solar_simulator.continuous_cli --input CHILD.json --target 31557600 --packet-steps 6 --output NEW_FOLDER
```

Каждый пакет равен 21600 с; эпохи совпадают с регулярной годовой сеткой:
1462 момента, 1461 пакет, 14620 строк тел. Backend Rust, rtol=3e-14,
контроль относительной пары Земля–Луна и прочие параметры прежние.

Критерии: вход и parent/child неизменны; SHA исходников, входов, native.pyd,
SciPy и выходов проверены. CLI: exit=0, status=complete; сохранить
experimental=True, automatically_scientifically_qualified=False,
controller_buffers_saved=False. CSV: точные названия, массы, порядок,
единицы SI, эпохи; пустое epoch_jd_tdb при origin=None, конечные значения,
без пропусков и перестановок. Все 1462 состояния CSV и final.json должны
побитно совпасть с continuousRust регулярной годовой траекторией.
Сравнивать uint64-представление float64, включая знак нуля; без допуска,
сортировки и интерполяции. Settings, финальное время и начальные данные совпадают.

Сохранить stdout/stderr, receipt, выходы и отдельный аудит, включая SHA
runtime и реального бинарника. При отказе сохранить входы и выходы,
найти причину в IO, границах пакетов или числах без подмены флагов и порогов.
Стоимость CLI измеряется отдельно с subprocess, CSV, JSON и диагностикой;
это не чистое время интегратора из годового стенда.

Успех подтверждает явно выбранный packet_steps=6 для этих трёх стартов,
Settings и годового интервала. Пакеты 20 ч и default GUI, произвольные параметры
и сближения требуют отдельной проверки. Здесь нет оценки физической точности,
JPL-сравнения или Noether21 budgets. Загрузка final.json создаёт новый контроллер.
Перенос окружения требует отдельной квалификации.
