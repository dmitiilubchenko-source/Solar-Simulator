
# 410E — доказательства continuous-year

**EVIDENCE CONTRACT TECHNICAL GO.** Внешний wrapper сохраняет
состояния и эпохи из уже вычисляемых снимков continuous-year. Полный
410R имеет статус NOT_RUN, счётчик запусков остаётся 0.
[Машинный отчёт](continuous-evidence-410e.json).

При явном current040 opt-in writer передаётся как абсолютный путь в
существующий изолированный subprocess. Он сохраняет `year-actual.npz`
в `continuous-year-raw` рядом с распакованным portable. Координаты,
скорости и фактическое время берутся из одного объекта снимка.
Порядок тел проверяется на каждом снимке. В NPZ пять полей, включая
запрошенную и фактическую сетки и массивы Unicode с именами и колонками.
Массивы состояний и времени имеют dtype float64.
[Захват состояния](../scripts/check_portable.py:595).

Оба файла записываются во временные siblings через flush/fsync и
публикуются через os.replace. NPZ читается обратно перед публикацией.
Manifest с `complete=true` и SHA опубликованного NPZ появляется последним.
При отказе сохраняются доступные partial для анализа, а исключение
достигает вызывающего процесса. Старый output directory считается
коллизией и сохраняется. `complete=true` означает целостную запись
evidence. Оценка проходит прежние численные assertions отдельно.
[Публикация](../scripts/qualification410e/writer.py:37).

Независимый reader связывает ZIP, runtime, native, сценарии, эталон,
wrapper, writer, stdout и полученные файлы. Он проверяет сетку и
порядок из закреплённого сценария. Индекс 3 в нём — Earth, индекс 4 —
Moon. Reader пересчитывает нормы годовых и относительных ошибок из
массива с `allow_pickle=False`, затем сверяет их со stdout и manifest.
Прежние пределы сохранены. Для года position < 0,1 м и velocity <
1e-6 м/с. Для Moon–Earth position < 0,1 м и velocity < 1e-5 м/с.
[Независимый пересчёт](../scripts/qualification410e/audit.py:55).

Для catalog используется уже создаваемый `snapshots.csv`. Reader
проверяет SHA CSV и receipt, порядок 354 тел, 3894 строки, обе временные
колонки и 11 групп эпох, затем пересчитывает отклонения существующей
матрицы. Дополнительный массив каталога не нужен.
[Аудит CSV](../scripts/qualification410e/audit.py:105).

**33 из 33 тестов** прошли под квалифицированным Windows Job supervisor
в Python 3.14.2t/NumPy 2.5.1. Набор включает контрольные случаи A–T,
изолированный запуск writer, захват через точный фрагмент loop с
синтетической сессией и сверку AST. Fault tests достигли заявленных
проверок. Повреждённые NPZ с обновлённым SHA проверены отдельно от
несовпадения SHA. Отказы записи, fsync и replace исключают появление
успешного manifest. Неподходящая provenance отклоняется. Подделка
всех связанных входов и результатов лежит за пределами этого
локального контракта целостности.
[Аудит и результаты](../scripts/qualification410e/independent-audit.json).

Прежний SHA wrapper
`e332fca075e4dd686c3011a0f644c19e2af2210025badffb8117f516d74687a7`.
Новый SHA wrapper
`e9bd0550e1c9bebad88c1cf4781c3e785e600f7f4b30d90a896fd9d1a633ebdc`.
Точный diff и AST после исключения evidence-добавлений подтверждают
неизменность численных циклов, импорта, IC, сценариев, порогов и
изоляции subprocess. Отдельно проверены байты неизменённых функций
fresh-year, GUI, recovery и recording. Native SHA и SHA ZIP совпали
с закреплёнными. Ветка 410R остаётся со своим исходным preflight STOP.
[Точный diff](../scripts/qualification410e/source-diff.txt).

Финальный тестовый процесс израсходовал 1,1875 CPU-секунды, supervisor
и вызывающий процесс 0,53125 CPU-секунды. Wall 1,82 с, максимальная
память выборки 139 419 648 байт. Подготовка, первые проверки и закрытие
учтены отдельным консервативным начислением.
[Журнал ресурсов](../scripts/qualification410e/resource-ledger.json).
