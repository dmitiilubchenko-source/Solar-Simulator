# Изменённые EIH + fixed J2 системы: протокол 193

15 октября 2026, до новых траекторий. Проверяются существующие уравнения
a=a_N+a_PN+a_Q: order-reduced harmonic EIH 1PN плюс ньютоновская J2 с
обратной силой. Не добавляются PN×J2/2PN силы, вращение, приливы или контакты.
Runtime, defaults, данные, схемы и прежние научные отчёты сохраняются.

Основа — eih_two из fixed_j2_ias.py: a=1e8 м, e=.2,
mu/(a c²)=1e-6, массы (.8,.2)mu/G, наклонная касательная (0,.8,.6),
COM offset (3a,−2a,a), drift (20000,−10000,5000) м/с. Alpha имеет
J2=.005, R=a/5, ось (0,0,1); Beta — J2=−.003, R=a/7, ось (.6,0,.8).
Это искусственные модельные тела, не реальные звёзды/планеты.
SI, заданная инерциальная система, t=0 — новый дочерний старт, без TDB/JPL.

Шесть заранее заданных веток: три одиночные правки при parent.time=0 и P/4.
P — первоначальный номинальный период, не подгоняется после правки.
Mass: Alpha.mass ×1.25. Position: Beta.position +a(.03,−.02,.04).
Velocity: Beta.velocity = Alpha.velocity +.9(Beta.velocity−Alpha.velocity).
Родитель P/4 рассчитывается прежним native advance_towards. Его состояние
не является независимым эталоном своей предыстории: проверяется свободная
эволюция нового, фактически записанного child IC. Сохранять parent/child SHA,
точные IC/массы/настройки и differences, без автоматического recentering.

61 равномерная выходная эпоха от0 до2P для каждой ветки. Settings наследуются:
dt=P/100, DOP853/per-body, rtol=3e-14, xatol=1e-7 м, vatol=1e-13 м/с,
relative_pair=None. Кандидаты: GUI/headless advance_towards пакетами20 с
Python и Rust; отдельно существующий native ContinuousRun с теми же
packet20 границами и эпохами. Legacy перезапускает solver, continuous
сохраняет контроллер; эти различия фиксировать. IAS15 здесь не нужен.

Независимый эталон — существующий RK45/полная матрица EIH/тензорный градиент
J2 из fixed_j2_ias.reference, без production force и DOP853. Length=1e8 м;
Mnorm=sum(actual child masses), clock=sqrt(length³/(G Mnorm)), все силы,
скорости, c и 21 компонент интегралов источников масштабируются согласованно.
Три уровня (rtol,max_step): (1e-13,P/200),(3e-14,P/400),(3e-14,P/800).
Начальный reference roundtrip <1e-6 м / 1e-8 м/с; интегралы при t0 нулевые.
Последнее уточнение <0.01 м / 1e-5 м/с по всем телам и Beta−Alpha,
нормированные компоненты интегралов <1e-10. Это эмпирическая чувствительность,
не строгая граница общей ошибки. Не заменять reference[0] на production IC.

Баланс принятого аддитивного усечения:
R2=H_PN a_PN, Rmix=H_PN a_Q, H_PN=∂²L_PN/∂v∂v.
Δ(E_EIH+V2)=∫Σv·(R2+Rmix)dt;
ΔP_EIH=∫Σ(R2+Rmix)dt;
ΔJ_EIH=∫[τ_Q+Σr×(R2+Rmix)]dt.
Как и в184, это учёт остатков усечённых уравнений, не новая физика.
Scales |E_child0|, Σm|v_child0| и |J_child0| вычислять из дочернего старта,
не из родителя. Интегралы reference начинаются с нуля нового опыта.

Кандидаты: каждое тело и Beta−Alpha <0.1 м / 1e-4 м/с;
все нормированные исправленные E/P/J <1e-9. Используются сходящиеся
интегралы вдоль reference, не отдельно интегрируемый budget кандидата.
До динамики: tensor/runtime J2 отдельно от point force <5e-13;
отдельная PN поправка Python/Rust против матрицы <3e-9 относительно PN.
Snapshot без source-reaction должен дать net force >1e-3 от суммы норм.
Отрицательный динамический контроль: если игнорировать τ_Q, raw J должен
измениться >1e-6. Raw E/P и раздельные PN²/PN×Q записать без требования
равенства нулю. Плохой reference или неполные/неконечные данные не могут
сертифицировать кандидата. Пороги после результатов не менять.

Точные IC/epochs/общие границы, побитовый повтор, source/input/actual native
.pyd/SciPy source SHA до/после обязательны. Legacy save/load continuation
должен совпасть побитово на одинаковом дальнейшем пакете. Для continuous
такого обещания после выгрузки checkpoint нет: буферы solver не сохраняются.
После одного прогрева/повтора — три чередующихся замера полных траекторий,
включая setup/снимки, без reference/diagnostics/hash/report. Сохранить все
времена; RHS legacy не измеряется и не заменяется числом пакетов.

Дополнительная проверка единиц до длинных расчётов: для mass-ветки начальный
SI source сравнить с reference integral/Δt при Δt=P×1e-7. Максимальная
ошибка после нормировки E/P/J должна быть <1e-5 относительно максимального
нормированного source. Это локальная проверка масштабирования бюджета,
не самостоятельное доказательство правильности формулы H_PN.

Переход к добавлению/удалению третьего тела потребует отдельной записи
до его траекторий. Никакой JPL-точности, гарантии для других правок,
горизонтов, сближений или между выходными эпохами этот блок не даёт.
