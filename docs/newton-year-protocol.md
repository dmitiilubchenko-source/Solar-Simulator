# Ньютоновский год: десять взаимно влияющих тел

Протокол171, 15октября2026, до расчётов. Исследовательский стенд;
строгий режим EIH/J2 приложения не изменяется.

IC — `solar-sandbox-strict-checkpoint.json`, SHA256
`65cd1b3eb5c815df11cd45a7106d8cc4ecb5828d10761715831aaf2571b3548d`.
Солнце, Меркурий, Венера, Земля, Луна, Марс, Юпитер, Сатурн, Уран,
Нептун; исходные float64 массы/состояния без переоценки параметров.
SI, SSB, Ecliptic J2000, JD2461321.5 TDB, DE441 provenance.
Из `continuous-integration-reference.npz` (SHA256
`e1cb054f6d5f2ca9b0e983e7f824fcd3e03e99c471266d8bfc3200bd74d67b55`)
используются **только125времён** `year_times`, 0–31557600с.

Обе программы решают точечную взаимную ньютоновскую гравитацию:
a_i=Σ(j≠i)Gm_j(r_j−r_i)/|r_j−r_i|³. G берётся из общего входного
контракта SI; ни PN, ни J2, ни вращения, ни контактов, ни смягчения.
Массы гигантов относятся к исходным барицентрам; новых спутников нет.
Это проверка численного решения, не сравнение с JPL и не оценка
наблюдательной/параметрической неопределённости.

## Независимый эталон

SciPy1.18.1 RK45, полный векторизованный массив взаимных взаимодействий,
переменные `[x,y,z,vx,vy,vz]` для каждого тела, AU/год,
независимое отображение Земля–Луна в EMB+относительный вектор.
Не вызывает runtime force/coordinates/DOP853/IAS15. Прямой относительный
вектор используется в силе Земля–Луна без вычитания абсолютных координат.
Три уровня (rtol,maxstepseconds): (1e-13,1800), (3e-14,900), (3e-14,450).
atol положения1e-17AU, скорости1e-17AU/год. Дополнительный последний
уровень AU/сутки с теми же **физическими** atol и maxstep450с.
RK45 использует quartic dense interpolation в заданных выходных эпохах;
сходимость проверяется на всей этой сетке, не непрерывная граница ошибки.

Последние два уровня и смена года на сутки должны согласоваться:
каждое тело <1м/<1e-6м/с; Moon−Earth <0.01м/<1e-7м/с.
Начальный roundtrip <0.002м/<1e-8м/с для всех и <0.0001м для пары.
Не заменять начальный округлённый результат эталона точным IC вручную.
Перед годом — пилот30суток на подмножестве исходной сетки + точный конец.
Если эталон не проходит, сохранить результат и не сертифицировать методы.

## Кандидаты и критерии

DOP853: existing ContinuousRun/nativeRust/per-body/relativeEarthMoon,
rtol3e-14, dt3600с, пакет20, сохранённый atol0.001м/1e-9м/с.
Отдельная чувствительность: atol1e-7м/1e-13м/с при том же rtol.
IAS15: optional REBOUND5.2.2, SI/directCartesian/basicgravity,
epsilon1e-9 и1e-11, PRS23/min_dt0, initialdt18с, exact_finish_time1.
Не сдвигать COM. Общие пакетные границы, контроллер сохраняется.
epsilon IAS15 не равен rtol DOP853.

Для каждого тела: <10м/<1e-4м/с относительно принятого независимого
эталона; Moon−Earth <0.1м/<1e-5м/с. Newton E/L/P drift <1e-10:
E нормируется на |E0|, L на |L0|, P на Σm|v0|.
Показывать все тела, уровни, отказы; не выбирать по JPL-остатку.
Энергия — полная многотельная, не формула изолированной пары.

Стоимость: прогрев +3чередующихся полных траектории каждого кандидата,
таймер включает setup/integration/снятие125состояний, исключает отчёт,
диск, хеширование, диагностику и callback. Дополнительный IAS15no-op
counter прогон вне таймера должен дать побитно те же массивы.
Повторные результаты также побитны; пакетные границы равны.
steps_done включает failedIAS15steps и не считается числом RHS.
Сравниваются реализации C IAS15 и Rustforce+Python/SciPyDOP853;
это не чистое сравнение методов, не GUI/FPS и не производительность EIH.
IC/grid/source/library SHA фиксируются до/после, rawNPZ/JSON сохраняются.

## Первичные источники

[SciPy RK45](https://docs.scipy.org/doc/scipy/reference/generated/scipy.integrate.RK45.html):
порядок5(4), quartic interpolation.
[Rein & Spiegel2015](https://arxiv.org/abs/1409.4779): IAS15.
[REBOUND IAS15](https://rebound.hanno-rein.de/integrators/ias15/):
смысл epsilon/PRS23, не абсолютная гарантия точности.
Текущая реализация и binaryREBOUND5.2.2 закрепляются SHA;
подробное происхождение optionalwheel — `ias15-comparison-validation.json`.
