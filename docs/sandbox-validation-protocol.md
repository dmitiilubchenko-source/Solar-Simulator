# Протокол первого блока песочницы

14 октября 2026, изменение 120. Зафиксирован до новых численных проверок.
Область этого блока — пользовательские точечные тела, ветки опытов,
сохранность исходного состояния и прежняя ньютоновская динамика.
Уравнения сил и интеграторы не меняются.

## Область и критерии

1. Необязательные астероиды/KBO/кольцо не требуются для импорта Experiment,
   пользовательской двойной системы и её checkpoint. Выбор каталожного
   сценария по-прежнему должен проверять источники и SHA, без fallback.
2. При t=0 без контактных событий initial и bodies должны совпадать по
   имени, массе, радиусу, положению, скорости и spin, включая порядок.
   Изменение вектора вручную отклоняется при расчёте и сохранении/загрузке.
   События контакта в t=0 сохраняют прежние допустимые скачки состояния.
3. Ветка получает копию текущих тел, t=0, прежние численные настройки,
   новый исходный баланс и origin=None. Родитель хранится целым checkpoint,
   с SHA канонического JSON; JPL-происхождение остаётся только у родителя.
   Неверные имена, пустой состав, совпавшие положения и несовместимые
   настройки отклоняются. Исходный опыт и его векторы не изменяются.
4. Основная проверка API веток — точечные массы без динамического вращения.
   Прежние контакты и фиксированные J2 сохраняются с прежними ограничениями;
   заданные во времени Q2 и динамическое вращение отклоняются.
   Замена тела, добавление, удаление и переименование не должны
   зависеть от имён планет. Сохраняется прежний предел checkpoint 1000 тел.
5. Bundle ветки хранит непосредственного родителя и текущий дочерний опыт
   одним атомарным файлом. Не обещается дерево всех предков. Старые схемы
   checkpoint 1–10 сохраняются; bundle имеет отдельный формат/версию.
6. Существующий редактор применяет изменения только после успешного
   сохранения bundle. Отмена или ошибка записи оставляет прежний опыт.
   Новый полный GUI добавления/удаления не входит в этот блок.

## Независимая модельная задача

Ньютоновская взаимная гравитация двух точечных масс: M=2e30 кг, m=7e29 кг,
начальная круговая относительная орбита r0=1.5e11 м. Плоскость наклонная:
u=(1,1,0)/sqrt(2), w=(0,0,1); скорость sqrt(G(M+m)/r0).
В дочернем опыте масса первого тела становится 2M; положения и скорости
сохраняются. Центр масс новой системы может двигаться: не обнулять его
искусственно. G=6.67430e-11 SI остаётся прежним.

Для относительной задачи после правки mu=G(2M+m), e=M/(2M+m),
a=r0/(1+e), rp=r0*(M+m)/(3M+m). Старт — апоцентр, не столкновение.
Эти выражения следуют из h²=mu*a*(1-e²) и v0²=G(M+m)/r0,
а не из вычисленных траекторий. Решать E-e*sin(E)=pi+n*t бисекцией
на независимой стороне и получать координаты/скорости эллипса.

64 выходных интервала на один новый период. DOP853: rtol=1e-13,
position_atol=1e-3 м, velocity_atol=1e-9 м/с, per-body.
Заранее заданные пределы: относительное положение <10 м, скорость
<1e-5 м/с; дрейф энергии и общего углового момента <1e-10 от исходных
масштабов. Для Verlet 1024/2048/4096 шагов отношение ошибок 3.8–4.2.
Python и Rust проверять отдельно; их совпадение не независимый эталон.
Записать стоимость, ошибки и источник начальных условий до/после.
Эти пороги проверяют данную задачу, не произвольные системы.

## Планетный профиль и источники

Предложен первый профиль Sun, Mercury, Venus, Earth, Moon, Mars,
Jupiter, Saturn, Uranus, Neptune из закреплённого solar-system-moon.
Названия внешних планет в наборе описывают точечные системы/барицентры:
их спутники не добавляются поверх системного GM. Предложен один юлианский
год (31557600 с), эпоха JD2461321.5 TDB, Ecliptic J2000, центр SSB,
геометрические векторы без аберрации, runtime SI. Состав и горизонт
утверждены ответом пользователя 14 октября: начинаем с 10 тел и года.
Численные пороги продукта и физические остатки относительно JPL требуют
отдельной квалификации выбранного профиля; этот блок её не заменяет.

Первичная годовая диагностика этого блока: Newton, 45 прежних закреплённых
эпох (плотная сетка первых 32 дней и годовые точки), DOP853 per-body,
Earth–Moon relative_pair, rtol=1e-13/3e-14, SI atol 1e-3 м и 1e-9 м/с.
Независимая сторона — RK45 с полной матрицей пар в безразмерных переменных,
rtol=1e-12/1e-13/3e-14 и atol=1e-15. До запуска диагностические критерии:
разность положения любого тела <100 м, скорости <1e-3 м/с,
чувствительность независимого решения <100 м. При отказе сохранить отчёт
и искать причину; не повышать пороги. Это численная квалификация данных
условий, не требование физической ошибки продукта. JPL-остатки выводить
по каждому телу и Earth–Moon отдельно без заявленного порога истинной точности.

Первичные источники соглашений:
[JPL Horizons manual](https://ssd.jpl.nasa.gov/horizons/manual.html),
[исходная реализация и описание DOP853 Hairer](https://www.unige.ch/~hairer/software).
Для изменённых пользователем условий реальные эфемериды не эталон;
используются аналитика, сходимость и соответствующие модели инварианты.
