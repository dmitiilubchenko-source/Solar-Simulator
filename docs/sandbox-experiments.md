# Ветки пользовательских опытов

Исходная версия от14октября2026, изменения120–122. Старая portable ZIP
не пересобиралась и этих новых возможностей не содержит.
В GUI добавлены [готовый профиль и ввод нового тела](sandbox-models-validation.md);
полная история/управление целевым временем ещё предстоят.

## Изменение существующего тела в окне

На паузе дождись завершения пакета, нажми «Изменить тело…», измени массу,
положение или скорость и примени как новый опыт. Выбери файл ветки JSON:
он атомарно сохраняет полный родительский опыт и дочерний старт. Только
после успешной записи приложение переключается на новый опыт при t=0.
Отмена выбора файла или ошибка записи оставляет прежний расчёт.

Притяжение звезды изменяется через её массу при неизменном G.
Положения и скорости других тел не корректируются автоматически;
итоговая орбита определяется уравнениями. Удвоение массы не означает
гарантированного падения всех планет. Радиус в текущем редакторе —
контактный; для DOP853 нужен нулевой радиус, физический размер отдельно не введён.

«Открыть JSON» открывает дочерний опыт из ветки. Обычный «Сохранить JSON»
сохраняет только текущий опыт: сохраняй первоначальный файл ветки, чтобы
иметь родителя. Возврат к родителю через отдельную кнопку пока не реализован;
его можно извлечь через API ниже и открыть обычный JSON.

## Headless API

Из корня исходного проекта, с его Python:

```python
from dataclasses import replace
from solar_simulator.experiment import preset, advance
from solar_simulator.sandbox import branch_experiment, save_branch, load_branch
from solar_simulator.storage import save
from solar_simulator.simulation import Body
from solar_simulator.vector3 import Vector3

parent = advance(preset("solar-system-moon"), 24)
sun = next(b for b in parent.bodies if b.name == "Sun")
branch = branch_experiment(parent,
    replacements=(("Sun", replace(sun, mass=2*sun.mass)),))
save_branch(branch, "масса Солнца x2.json")

# Восстановить непосредственного родителя, включая его время и историю.
restored = load_branch("масса Солнца x2.json")
save(restored.parent, "исходный опыт.json")

# Пользовательское тело: инерциальные SI координаты и скорость, не шаблон орбиты.
extra = Body("My star", 1e30, Vector3(0., 0., 1e13), Vector3(0., 0., 0.))
another = branch_experiment(parent, additions=(extra,))
# Удаление не требует изменения гравитационного алгоритма.
without_sun = branch_experiment(parent, removals=("Sun",))
```

Вычисления используют прежние Settings родителя. У опыта с относительной
парой удаление/переименование одного её тела отклоняется; пара молча не
заменяется. Сначала нужно явно выбрать совместимые настройки другого опыта.
Названия пользовательских тел не регистрируются в каталоге JPL.

## Сохранность и ограничения

- Формат `solar-experiment-branch`, version 1, оборачивает обычные checkpoint
  схем 9/10; загрузка старых checkpoint 1–10 сохранена. Обычный CLI `inspect/run`
  пока принимает checkpoint, а не bundle: извлеки `restored.child` через `save`.
- Родитель — неизменяемая строка канонического JSON с SHA256; свойство
  `parent` каждый раз возвращает отдельную копию. Контрольная сумма обнаруживает
  повреждение, но не является подписью автора или независимым доказательством данных.
- Дочерний старт отделён от родителя: t=0, собственная исходная энергия,
  пустая история событий/потерь, `origin=None`. Прежние кадры не используются
  как траектория дочернего опыта. `changes()` показывает точные записи до/после.
- Bundle сохраняет непосредственного родителя, не рекурсивное дерево предков.
  Размер ограничен 10 MB, один checkpoint — 1000 тел; хранение обоих состояний
  увеличивает размер. Смена Settings дочернего опыта внутри этого bundle
  отклоняется: новый численный эксперимент оформляй отдельно.
- Существующие контакты и фиксированные J2 сохраняют прежние guards.
  Заданная во времени Q2 и динамическое вращение пока нельзя редактировать:
  их ориентация/инерция требуют отдельного научного контракта.
- Векторы ядра остаются изменяемыми. Теперь рассогласование initial/current
  при t=0 без событий отклоняется при расчёте и save/load; это не универсальная
  защита от любого ручного изменения памяти после начала расчёта.
- GUI добавления имеет два учебных шаблона массы и явные SI векторы.
  Расчёт вперёд до времени уже доступен: [контракт и проверка](time-control-validation.md).
  Удаление кнопкой, возврат к прошлому времени без загрузки,
  расширение к 30 телам и физические критерии близких сближений ещё предстоят.
