# Solar-Simulator 0.4.0

Настольная физическая лаборатория для Windows x64. Относительно принятой 0.3.2 версия развивает
модель собственного консервативного вращения, чтение состояния вращения в Laboratory и диагностику
надёжности расчёта и записанной траектории. В этом выпуске доступна **не более одной динамической Q2-фигуры**.
Две и более временно недоступны; это не ограничивает число обычных тел или фиксированных J2.
Архивная демонстрация двух фигур не является интерактивным режимом этой версии.

## Возможности и запуск

- Ньютоновское взаимодействие; допустимые EIH 1PN и FixedJ2 сочетания. Несовместимые модели явно отклоняются.
- Python и Rust native backend; прежний рабочий DOP853 и другие существующие поддерживаемые режимы сохранены.
- Laboratory, save/load/recovery, запись и воспроизведение траекторий, экспорт CSV.
- Portable для Windows x64 с графическим рабочим столом; Python и зависимости входят в ZIP.
- Распакуйте ZIP в отдельную папку и запустите `Solar Simulator.cmd`.
- Перед обновлением скопируйте пользовательские JSON/CSV/траектории. Храните их вне папки установки.
  Не устанавливайте поверх прежней версии; старые файлы и научные архивы не перезаписываются.

Исторический APPLICATION_D1=NO_GO не заменяется допуском ограниченного продукта.

прежние области квалификации; актуальная продуктовая область определяется этим описанием0.4.0.

Публичный source commit отличается от исходного419: приватные operational-записи и один одноразовый
локальный sealing driver исключены из отдельной истории; исполняемый состав, стандартные сборочные
скрипты, тесты, зависимости и научные входы побайтово сохранены. Исходная локальная история не изменена.
Квалификация419 относится к оригиналу и ZIP; новый Git ID не выдаётся за непосредственно прошедший старую suite.

и в [отчёте публикации](release-040-4201.md). Старые SHA в verification не заменены.

Строгая проверка numerical recipe отличает это окружение от произвольного другого.
