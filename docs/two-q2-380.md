# Две динамические Q2-фигуры: модель380

29 октября2026. Это headless-расширение существующего RotationDOP853,
не другой интегратор и не продолжение max_step379. Все реальные лунные
данные/старые численные отчёты остаются прежними. Новых параметров Земли
или Луны нет: проверка использует явно синтетические A/B и точку C.

## Постановка и вывод

Опора: [Chen, Li & Tao2021, GRIT](https://arxiv.org/html/2103.12767v2),
двойной интеграл Newton potential, Hamiltonian и Taylor expansion Appendix A.
Уравнения ниже самостоятельно получены из интеграла через COM и главные I.
Интегратор Solar
остаётся SciPy DOP853, не симплектическая схема GRIT.

Для тела i масса Mi, постоянная body-inertia Ii, R_i:body→inertial,
q_i=(w,x,y,z), S_i в инерциальном базисе. Specific quadrupole:

```text
Qi = Ri (3 Ii − tr(Ii) 1) Riᵀ / Mi                    [m²]
omega_i = Ri Ii⁻¹ Riᵀ Si                             [s⁻¹]
qdot_i = (0,omega_i) ⊗ qi / 2
Sdot_i = tau_i                                        [kg m²/s²]
```

Рассматривается разложение **суммарной степени2** по размерам тел относительно
расстояния. Диполи исчезают при выборе COM каждого тела. Для r=xj−xi,
d=|r|, n=r/d, Q=0 у точек, k=G Mi Mj:

```text
Uij = −k/d + k nᵀ(Qi+Qj)n / (2 d³)
Fj = −k n/d² − k [(Qi+Qj)n − (5/2)nᵀ(Qi+Qj)n n] / d⁴
Fi = −Fj
tau_i(from j) = k n×(Qi n)/d³
tau_j(from i) = k n×(Qj n)/d³
```

Каждый M-Q член добавляется ровно один раз для каждой фигуры. Два члена
для пары фигур — это Mi–Qj и Mj–Qi, а не удвоение монополя.
Ньютоновский monopole считается один раз для каждой пары всех тел.
Сила следует из −grad_r U. Независимая вариация Ri→exp(hat(delta theta))Ri
даёт delta U=−tau_i·delta theta. Поэтому
`r×Fj + tau_i + tau_j = 0`, а сумма сил равна нулю.

Общие инварианты усечённого Hamiltonian:

```text
H = sum_i Mi vi²/2 + sum_fig Si·omega_i/2 + sum_i<j Uij [J]
P = sum_i Mi vi                                         [kg m/s]
L = sum_i xi×Mi vi + sum_fig Si                          [kg m²/s]
```

Sdot записан в инерциальном базисе, поэтому body Euler-терм Pi×Omega здесь
не добавляется. Независимый reference использует именно body Pi и R:
`Rdot=R hat(Omega); Pidot=Pi×Omega+tau_body`. Две реализации сравниваются
по физическим R/S, а не по неоднозначному знаку кватерниона.

## Чего в модели нет

Q2–Q2 имеет степень4 и масштаб `G Mi Mj ai² aj²/d⁵`; он **не включён**.
Не включены и остальные высшие мультиполи. У общего нецентросимметричного
распределения уже степень3 может дать ненулевой остаток; у центрально
симметричного тела нечётные моменты исчезают, но при степени4 кроме Q-Q
возникают monopole–hexadecapole члены. Одни I не задают эти моменты.
Таким образом это консервативная усечённая модель, не полная физика двух тел.

Для двух фигур требуется d>Ra+Rb; для фигуры и точки d>Rfigure. Это безопасная
внешняя область ограничивающих сфер, не физическая collision detection и
не гарантия малой ошибки у поверхности. Проверка выполняется также в RHS.
Нет деформации, приливов, диссипации, EIH-смешанных членов, контактов или
одновременных FixedJ2/PrescribedQuadrupole. Body.radius/passive spin нулевые;
вращательное S хранится отдельно. Инварианты относятся к этому Hamiltonian.

## Карта изменений и совместимость

- `nbody_rotation.py`: одна или две уникальные фигуры, sum existing M-Q
  corrections, раскладка6N+7K, отдельные q/S error blocks и оба spin-вклада.
  Старый singular correction и int-return validate для одной фигуры сохранены;
  для двух validate возвращает tuple индексов в порядке RotationState.
- `experiment.py`: initial norm каждого q. `storage.py`: прежняя schema10
  с теми же полями/модельным tag, в списках теперь допустимы1/2 состояния.
  Новая версия читает старые файлы; старый reader отвергает два состояния,
  не отбрасывает второе. Нормирование q для R не переписывает raw q.
- CLI/inspection/convergence: полные E/P/L, torque каждого тела и sum torque,
  оба блока сравнения. Для0/1 прежний JSON не меняется.
- Rust core/native: произвольное N монополей уже поддерживается, новые Q/S
  остаются в существующем Python/SciPy пути. Бинарник не пересобирается.
- Branch editor по-прежнему явно отвергает dynamic rotation. Headless API,
  load/advance/save и существующее GUI открытие работают через Experiment.

Пример создания без новых реальных planetary inputs:

```python
from scripts.two_q2_fixture380 import fixture
from solar_simulator.experiment import create_experiment, advance
from solar_simulator.storage import save
bodies, rotations, settings = fixture()
experiment = create_experiment(bodies, settings, rotations=rotations)
save(advance(experiment, 2), "two-q2-example.json")
```

## Заранее заданная проверка

Авторитетные exact IC/эпохи/допуски/исходники и criteria перед запуском:
`scripts/two-q2-380-plan.json`. Синтетические2/3 тела,65 эпох0..4000s,
64 одинаковых cold packets; Python/Rust point forces. Три уровня rtol:
1e-9/1e-11/3e-13, соответствующие абсолютные допуски заданы в plan,
прежние публичные defaults/старые критерии не меняются. Основной runtime
не получает max_step. Reference: scaled Cartesian/R/body-Pi RK45,
3e-11/3e-13, max_step50s только для независимого reference.

G=6.67430e-11m³kg⁻¹s⁻², M_A=1e15kg, M_B=2e14kg, M_C=3e12kg;
Rbound_A/B=1000/900m, начальная rho_AB=(12000,0,0)m,
v_rel=(0,2.55,.2)m/s. Все I/q/S/COM/drift и C координаты приведены точно
в machine plan. Инерциальная синтетическая система, t=0 произвольное начало
elapsed SI seconds; это не JPL/UTC/TDB-эпоха реальной Солнечной системы.

Независимые position/attitude potential gradients2e-6, action/reaction1e-13,
local angular balance2e-12. При движении relative H/L<1e-8, P<1e-12,
norm(q) drift<1e-8, fine/reference difference<1e-7, reference sensitivity<1e-8.
Primary tolerance comparison должен показывать уменьшение ошибки между
standard/fine против coarse/fine. Это эмпирическая проверка, не строгий bound.
Проверяются same-packet save/resume, global rotation/translation, spherical
limit и старые0/1 canonical snapshots. Потенциал дифференцируется отдельно
в principal-I форме, не через функцию силы и не по одной energy conservation.

Budget нового scientific worker120CPU/300wall/1GiB/64MiB; ранний guard110/280/
900MiB/56MiB, cooperative95/250. Оценка10..60CPU,<256MiB,<8MiB, включая
reference/observer; регрессии/подготовка учитываются отдельно. Данные exclusive,
каждый job journal сохраняет завершённые состояния; partial/fail не удалять.

битовое совпадение на произвольной версии NumPy/SciPy или другом устройстве.

**Решение:** GO для ограниченного headless Newton/degree2 режима двух фигур
в проверенной внешней области. Нет GO для полной физики двух протяжённых тел,
точности реальных Earth/Moon, старой current375 annual qualification или релиза.
Обязательная свежая source-bound квалификация перед новым release остаётся
отдельной задачей; одно синтетическое испытание не заменяет её.

Следующий небольшой практический шаг: открыть существующий read-only reliability
отчёт в Laboratory без нового физического режима; затем квалификация актуального
runtime перед0.3.3. Не добавлять автоматически приливы или новый интегратор.
