# Автономная проверка и расчёт для демонстрации146–149

Проверочный комплект делает опубликованное сравнение125эпох/10тел/года
воспроизводимым без исходного проекта, приватного кеша и сети.
[Протокол до проверки](verification-bundle-protocol.md), [показатели JPL](dense-jpl-validation.md).
Модель, начальные данные, допуски и физические уравнения остались прежними.

В комплекте только явно выбранные научные данные:40ответов Horizons DE441,
точные сохранённые траектории трёх квалифицированных профилей, исходный
датасет/GM, строгий checkpoint, опубликованные отчёты и проверочные скрипты.
JSONперенос траекторий совпадает с исходнымNPZбез округления. Manifestсвязывает
SHA полезной нагрузки и происхождение данных. Личные документы/весь.tools/
пользовательские опыты не входят. Для доверия к передаваемому manifest нужно
сверить опубликованный SHA всегоZIP; checksumсам по себе не доказывает физику.

## Два отдельных запуска

`JPL Verification.cmd` пересчитывает остатки **сохранённых траекторий**.
Он сверяетSHA, первичные таблицы, единицы/координаты/эпохи/GM/начало/настройки,
затем самостоятельно вычисляет нормы ошибок через `math.hypot`. Solar,
GUI и интегратор не импортируются. Отчёт145 совпал в пределах1e-9м/1e-12м/с.
Это воспроизведение сравнения, не новый расчёт движения или независимые силы.

`Physics Verification.cmd` выполняет **новый свободный годовой расчёт**
строгого10bodyRustпрофиля: EIH1PN+фиксированныеSun/EarthJ2, DOP853/per-body,
relativeEarthMoon, rtol3e-14, dt3600с, packet20,125эпох. Он сверяет
runtimeисходники с квалификацией141 и сравнивает сJPLи сохранённой траекторией.
РезультатJSONсохраняется рядом с каталогомverification, без изменениякомплекта.
НезависимыйRK45эталон и его численные проверки остаются отдельным аудитом141.

В исходном проекте можно выполнить:

```powershell
.\.venv\Scripts\python.exe -X utf8 -B -m scripts.export_jpl_bundle --output "новый каталог"
.\.venv\Scripts\python.exe -X utf8 -B -I "новый каталог/replay_jpl.py" "новый каталог"
.\.venv\Scripts\python.exe -X utf8 -B -I "новый каталог/recompute_jpl.py" "новый каталог"
```

Экспорт использует прежний квалифицированныйкеш и проверяет егоSHA.
Готовый переносимый комплект после экспорта/извлечения уже не требуеткеша.
Исходный каталог экспорта должен быть новым: ранее проверенные результаты
не перезаписываются. NumPyдляreplay и Solarдляновогорасчёта входятвportable.
