# Автономный читатель DE441: протокол236

16 октября2026, до новых сравнений. Сеть не использовать. Задача —
проверить чтение первичного эталона; это не новый интегратор, сила или
независимое подтверждение самой астрономической эфемериды.

Исходники: локальный резерв234–235, manifest SHA
`9bb19c96de7c5be71fb97fccff39c4ea8ced1fe8100d19a294a18a91e48a5b75`,
публичный `offline-sources-validation.json`, официальный ASCIIformat,
DE441 header и115полных записей306–420. Проверить SHA до использования,
сохранить отдельный небольшой архив для воспроизведения без старой.tools.
Первичные документы доступны локально; сеть/Consensus сейчас не требуются.

GROUP1050:1-based offset, число коэффициентов на компоненту, число
подинтервалов. Нативные позиции ICRF/SSB в TDB-compatible km;
время — секунды TDB отJD2461321.5, не UTC. Общая запись32суток,
подинтервалы различаются по телам. x=2(t−t_start)/span−1.
Скорость/ускорение — аналитические производные полинома с множителями
2/span_seconds и его квадратом, затем km→m. Никакого сложения большой
floatJD на каждом обращении. Экстраполяция/клиппинг даты запрещены.

Earth=EMB−Moon_geo/(1+EMRAT), Moon=Earth+Moon_geo; те же линейные
преобразования для производных. Относительную Луну получать прямо из
геоцентрических коэффициентов, без вычитания двух AU-векторов.
ICRF→EclipticJ2000: фиксированный поворот Rx(−ε), ε=84381.448arcsec,
как в сохранённом руководстве Horizons; производные имеют тот же поворот.
Sun/8planet/Moon, внешние планеты — системные барицентры, не новые спутники.
Плутон в сыром файле не входит в нынешний runtime/критерий10тел.

Номинальный интервал440эпох:31557600с, те же реальные20hвыходы215.
JPL из закреплённого `nominal-jpl440-inputs.zip`: повторный parser/ID/
DE441/SSB/TDB/геометрические векторы/Origin/порядок/SHA. Кандидатные
траектории не интегрировать и не подгонять. Сначала проверить читатель.

Два разных критерия, объявленные до результата:

1. Строгое численное совпадение читателя со всеми440JPLвыходами: для каждого
   тела <.01м/<1e-8м/с; Moon−Earth <.001м/<1e-8м/с.
2. Отдельная проверка представления времени по229:100мкс инженерный
   envelope, body10м/pair.2м плюс исходные допуски совпадения. Она не
   отменяет strict FAILED и не квалифицирует читатель вместо пункта1.

Не обещать совпадения внутренних эпох Horizons: печатныйJD округлён,
календарная отметка совпадала с целыми секундами. Диагностически вывести
ошибку roundtrip большогоfloatJD и оценку |v|δt; не корректировать векторы
и не выбирать эпохи/обликуитет/EMRAT по лучшему остатку.

Независимые проверки:

- Синтетические известные полиномы с ненулевыми второй/третьей степенями:
  значения и две производные, единицы, обратное восстановление EMB,
  выбор подинтервала/границы, неверные/неподдерживаемые времена/данные.
- На10номинальных индексах0,1,2,13,55,110,220,330,438,439: отдельная
  Decimal70/90 recurrence дляT_n,T'_n,T''_n на тех же floatкоэффициентах.
  70→90 покомпонентно |Δ|/max(1,|value|)<1e-50; double vs90digits
  все тела <.01м/<1e-8м/с/<1e-12м/с², relative <.001м/<1e-8/<1e-12.
- Все внутренние границы записей/подинтервалов115records, активные11
  позиционных колонок: слева/справа <.01м/<1e-7м/с/<1e-9м/с².
  Это проверка согласованности полиномов, не точности симулятора на10лет.
- На тех же10эпохах, где доступны±h: центральные разностиh1000,100,10с;
  последняя относительная ошибка dp/dt <1e-6 и dv/dt <1e-5 по каждому
  телу, делитель max(norm(analytic),1e-12). Уточнения вывести все;
  немонотонность не прятать и не считать разность строгой границей ошибки.
- Негативные контроли: отсутствует Rx, неправильный знак поворота,
  Earth ошибочно EMB, EMRAT81.3 вместо заголовка, скорость km/day вместо
  km/s. Каждый должен провалить строгую сверку хотя бы одного тела.
  Порча SHA/неполный набор/NaN/выход за диапазон отклоняются явно.
