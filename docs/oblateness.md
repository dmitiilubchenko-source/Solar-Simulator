# Несферичное притяжение: фиксированная ось J2

Модель добавляет первый осесимметричный квадруполь внешнего гравитационного поля.
У Земли J2 описывает ведущую поправку к сферическому притяжению. Реализован
общий FixedJ2 для именованного тела; готовый профиль earth-j2 относится к
закреплённому десяти-тельному solar-system-moon. Это ограниченная модель,
а не полная динамика вращения Земли и Луны.

## Параметры и происхождение

J2E = 0.00108262539 без нормировки, RE = 6378136.6 м. Это номинальные константы
из официального [заголовка DE441](https://ssd.jpl.nasa.gov/ftp/eph/planets/ascii/de441/header.441).
SHA-256: 376cd6f6766356ba0f4c25dc5a7ff8130ea2826f3c34149e33c1e6ac970d6e7c.
Их временные изменения здесь не включены.

Начальная ось вычислена по BODY399_POLE_RA/DEC из
[NAIF pck00011](https://naif.jpl.nasa.gov/pub/naif/generic_kernels/pck/pck00011.tpc)
(SHA-256 3dff7b1dbeceaa01f25467767d3fa25816051c85d162d1edf04acb310ee28bb1):
RA = -0.641 T, Dec = 90 - 0.557 T градусов, T = (JD_TDB - 2451545)/36525.
Правила полиномов и единицы приведены в [PCK Required Reading](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/req/pck.html).
Это приближённый IAU-полюс; он не воспроизводит ориентацию Земли в DE441.
Ось заморожена на начальной эпохе JD 2461321.5 TDB и не переоценивается при restart.

Экваториальный вектор (cos Dec cos RA, cos Dec sin RA, sin Dec) преобразуется
в Ecliptic J2000 вращением вокруг X на -epsilon. Здесь epsilon = 84381.448
угловых секунд, согласно [описанию системы координат Horizons](https://ssd.jpl.nasa.gov/horizons/manual.html#ecliptic).
В частности, экваториальный северный полюс имеет положительную Y-компоненту
в этой эклиптической системе. Нельзя просто считать ось Земли осью Z сценария.

Профиль earth-j2-20261008.json и его SHA-256
f078a600e0da97fcf1c63e462c1af8b60f75d9fa336382a79ee436e404a14be1
поставляются с пакетом. Проверяется целостность профиля; параметры/ось/происхождение
полностью записываются в JSON схемы 6. Старые схемы 1–5 мигрируют с пустым списком фигур.
Запись сохраняет ранее выбранные физику и интегратор, не добавляя J2.

## Потенциал, сила и диагностика

Для источника i с массой mi, единичной осью s, опорным радиусом R,
мишени j и r = rj - ri, n = r/|r| дополнительная энергия пары:

    V2 = G mi mj J2 R² [3(n·s)² - 1] / (2 |r|³)

Поправка к ускорению мишени:

    aj2 = 3 G mi J2 R² / (2 |r|⁴) · [(5(n·s)² - 1)n - 2(n·s)s]
    ai2 = - (mj/mi) aj2

Реакция учитывается для всех мишеней, включая Солнце и другие планеты. Если
оба тела имеют фигуры, суммируются два разных взаимодействия figure/point;
quadrupole/quadrupole не включено. Соглашение о ненормированных гармониках и
реакции соответствует разделу 3.2 [Park et al., DE440/441](https://ssd.jpl.nasa.gov/doc/Park.2021.AJ.DE440.pdf).

В ньютоновском режиме стационарный потенциал сохраняет энергию и линейный
импульс. Фиксированные оси нарушают общую вращательную симметрию: орбитальный
L может меняться. Для одной оси сохраняется проекция L на неё. Выводится
instantaneous figure_orbital_torque в кг·м²/с². В связанной модели противоположный
момент действовал бы на вращение; сейчас вращение не интегрируется.

При EIH 1PN добавляется ньютоновская сила J2 и её энергия. Смешанные члены J2/c²
опущены. Диагностика Нётер 1PN плюс V2 поэтому сохраняется только в точности
принятого усечения; остаток нельзя объявлять чистой численной ошибкой.

Доступно Python/DOP853, без контактов и пассивного spin, при 0 < |J2| <= 0.01,
единичной оси и расстоянии от источника строго больше R. Область проверяется
при создании, загрузке и вычислении силы. R не является контактным радиусом;
движение внутрь него отклоняется. Разложение вблизи поверхности без высших
гармоник не становится точной физикой лишь потому, что расчёт допустим.

## Измерения на одинаковых начальных данных

Обе колонки используют те же 10 тел, GM, DE441-эпоху, EIH 1PN, допуски и
45 контрольных эпох на один юлианский год; изменяется только включение Earth J2.
Параметры не подбирались по положению Луны. Максимальная норма отклонения, м:

| Величина | Сферические точки | Earth J2, фиксированная ось |
|---|---:|---:|
| Земля относительно SSB | 391.66 | 161.54 |
| Луна относительно SSB | 25323.48 | 670.68 |
| Барицентр Земля–Луна относительно SSB | 164.60 | 162.13 |
| Луна относительно Земли, год | 25611.85 | 637.14 |
| Луна относительно Земли, первые 32 суток | 2010.50 | 53.34 |

Независимый RK45 использует безразмерные AU/year и другой вид силы: градиент
тензорного потенциала Q = J2 R²(3 ssᵀ - I), а также независимую скалярную EIH.
Три допуска 1e-12/1e-13/3e-14 проверяют сходимость эталона. Между двумя последними
расчётами до 1.636 м; согласование production до 7.676 м по Луне, 0.095 м по
Земле и 0.294 м по Меркурию. Скоростные разности <1e-4 м/с для всех тел.
Ужесточение production rtol до 3e-14 изменяет координаты до 2.203 м.
Максимальный относительный остаток энергии всей системы 4.28e-15; эта величина
не ограничивает ошибку лунной фазы (энергию системы в основном задают планеты).
[Полные измерения](oblateness-validation.json).

Проверки силы: аналитические экватор/полюс, complex-step градиент независимого
P2-потенциала для трёх тел/двух фигур, тензорная формула, реакции, сдвиги/вращения
и обращение оси. Независимо проверяются сохранение E/P/L·s в наклонной
эксцентрической ньютоновской паре, физическое изменение полного L, момент силы,
контрольные точки/restart, GUI/CLI и месячный RK45-эталон.

## Воспроизведение и запуск

```powershell
.\.venv\Scripts\python.exe -B scripts/fetch_figure_profile.py --cached
.\.venv\Scripts\python.exe -B scripts/assess_oblateness.py
.\.venv\Scripts\python.exe -B -m solar_simulator new solar-system-moon j2.json --physics eih-1pn --figures earth-j2 --dt 3600
.\.venv\Scripts\python.exe -B -m solar_simulator run j2.json year.json --steps 8766
.\.venv\Scripts\python.exe -B -m solar_simulator gui j2.json
```

Без --cached профиль запрашивает официальные текстовые источники с TLS-проверкой
и сверяет закреплённые SHA; изменённый источник требует пересмотра данных.
Кеш хранится локально в .tools, в runtime сетевых запросов нет.
