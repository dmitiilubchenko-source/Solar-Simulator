# Приёмка кандидата 0.3.2

25 октября 2026, изменение 369. Проверка начата; результаты добавляются по факту.
Состав — [maintenance-032](development/maintenance-032.md),
[описание выпуска](releases/v0.3.2.md). Принятая main остаётся 0.3.1.

До изменения версий сохранены точные manifests/locks и проверочные источники
0.3.1 в scripts/validation/release031-sources.zip; их SHA сверены с принятым
отчётом 0.3.1. Старые release031-history.json, release030-sources.zip,
научные JSON/NPZ и численные пороги сохраняются. Новый release032-history.json
задаёт явные допустимые пары для прежних научных replayers; общий framework
истории не добавляется. Исторический replay не квалифицирует текущий runtime.

Физические исходники Python/Rust и данные не меняются. Проверяются новые
метаданные, настоящие binaries, полная source/native-приёмка без skip,
совместимость файлов настоящей portable 0.3.1 и новый изолированный ZIP.
Штатная ZIP-приёмка включает свежий годовой Strict-расчёт по сохранённым
JPL-входам; это проверка ограниченного сценария, а не обещание лучшей точности.
Предыдущий принятый ZIP/SHA и LATEST сохраняются до успешного завершения.

## Реальная поставка

ZIP `SolarSimulator-0.3.2-20261025-121729.zip`, **112312650 байт**. SHA256:
`7c578220ec77e792aa9589f32a30352e88277d0d096bff0ad3ca5aae9c014c49`.
Сборка 43.964с, relocation/приёмка 209.252с.
CRC, свежая распаковка в путь с пробелами, изоляция runtime/Tcl/LOCALAPPDATA,
исключение личных файлов и research dependencies прошли. 79
файлов пакета и четыре публичных архива совпали с исходниками побайтно;
native в поставке совпал с проверенным pyd. Штатные GUI/CLI, сохранение/закрытие/
recovery/продолжение, editor/parent, запись/playback/сравнение/replay прошли.
Отдельный patch probe подтвердил шесть сохраняющих переходов и шесть отказов
записи, parent/current, отмену загрузки и отзывчивость Tk. Реальные пользовательские
recovery и траектории не удалялись. Caller profile сохранён, smoke-каталоги убраны.

Настоящая portable 0.3.1 создала checkpoint/parent и три кадра 0/20/40с для
Python DOP853 и Rust Verlet. 0.3.2 читает их и продолжает с побайтным совпадением
канонического состояния, включая знак нуля, при одинаковых границах пакетов.
Исходные записи неизменны. Строгий replay отклоняет смену application version,
для Rust также native; старый recipe не переписывается.
