# Приёмка подготовленной версии 0.3.0

Версия подготовлена в dev; main, v0.2.0 и публикация GitHub Release не менялись.
[Состав0.3.0 и ограничения](releases/v0.3.0.md). Старый проверенный RC и315/155
сохраняются. Номер0.3.0 сам по себе не означает принятия конкретного ZIP.

## Проблема и исправление

В324 оба проверочных процесса сборщика наследовали профиль вызывающего.
Это воспроизведено контролируемым запуском прежнего subprocess-вызова:
настоящий save_recovery записал checkpoint в тестовый caller LOCALAPPDATA.
Реальный профиль пользователя в эксперименте не использовался.

Теперь run_build_smokes выделяет уникальный tempfile-каталог в tools вне
выходного ZIP. Оба процесса используют один LOCALAPPDATA/MPLCONFIGDIR;
внешние PYTHONHOME/PYTHONPATH/TCL_LIBRARY/TK_LIBRARY удалены, PATH вWindows
содержит только системные каталоги. Словарь env родителя не меняется.
Перед уборкой проверяется абсолютный tools/scratch путь. Удаляется только
собственный временный профиль после выхода процессов, включая отказ.
Пользовательские recovery, данные и прежние сборки не удаляются.

Два регрессионных сценария запускают настоящие дочерние процессы: создание
recovery, чтение во втором процессе, затем успех или контролируемый exit7.
Проверяются сохранность caller-sentinel, неизменность parent env, общий
профиль, размещение внеZIP, отсутствие временного профиля после завершения
и передача ошибки вызывающему. Это проверка процесса сборки, не численного ядра.

## Неудачные проверки

До реализации2FAIL0.36с: отсутствовал новый runner. Это тест требуемого
контракта, а не отдельная полная сборка старой версии; прежнее наследование
профиля дополнительно воспроизведено настоящим save_recovery выше.
Первая реализация дала2FAIL0.45с: после os.environ.copy() обычныйdict имел
SYSTEMROOT, а код обращался как к нечувствительному к регистру os.environ.
Исправлено чтением SystemRoot через os.environ.2PASS5.54с; расширенный
набор упаковки/документов/реальных GUI-проб:15PASS48.56с.

Root/native pyproject, Cargo и locks согласованы на0.3.0, установленный native
и standalone-core пересобраны. pip check успешен, runtime-зависимости не обновлялись.
Документ поставки берётся из releases/v<актуальная версия>.md, не из старогоRC.

три кадра0/20/40с читаются, parent сохранён; исходные файлы неизменны.

двух проверочных процессов сработала; ZIP не содержит проверочных профилей.

совпали с исходниками;4научных ZIP и настоящий native pyd тоже побайтно
совпали. Личные файлы/.tools исключены. Версии/импорты принадлежат runtime.

full+stopped replay прошли для Python/DOP853 и Rust/Verlet. Полные кадры,
