# Протокол диагностики 354 тел

15 октября 2026, до измерений. Измеряется текущий Windows-компьютер.
Начальные данные SI/SSB/EclipticJ2000, JD2461321.5 TDB, прежние GM.
Профили10/27/354 различаются составом, поэтому их время не является
сравнением точности или ускорением одной модели.

Для готовых научных профилей: Rust point EIH1PN + fixed Sun J2 + prescribed
Earth/Moon Q2, DOP853/per-body/relative Earth–Moon; rtol3e-14,
position_atol1e-7 м/velocity_atol1e-13 м/с, dt3600 с, packet20.
Дополнительно354Newtonian/DOP853 без фигур, с default GUI допусками
rtol1e-13/position_atol1e-3 м/velocity_atol1e-9 м/с, Python и Rust:
это сравнение backend, не замена научного профиля.

Один прогрев и3повтора advance на72000 с от идентичного старта;
отдельно report конечного состояния, point-force adapter,
готовые owned-list аргументы native, Python conversions безnativeforce.
Эти microbenchmarks не полностью аддитивны и не доказывают стоимость
чистого FFI. Число RHS/время callback и cProfile — отдельные наблюдения,
не включаются в обычные измерения walltime.
Сохраняются raw samples, версии, CPU/потоки, SHA исходников/входов/выходов.

Настоящий Tk1180×820/Matplotlibcanvas: истории60 и1500, все тела и
Earth–Moon. Истории построены повторением двух настоящих снимков
только для нагрузки renderer, не считаются длинным научным прогнозом.
Прогрев+3повтора, построениеartists и canvas.draw отдельно; вывод
через синхронный draw, без нагрузки worker/poll. Кадры не прореживать.

Если подтвердится локальное узкое место, до измерения кандидата критерий:
не менее15% уменьшения медианы полного пакета или fullrender354/1500/all
на тех же входах/настройках, минимум3повтора с прогревом. Отдельные вызовы
с ускорением менее15% недостаточны. Полные состояния и диагностические
значения должны совпадать точно; путь, маркеры, история, легенда, подписи,
лимиты сохраняются. Если изменяется порядок арифметики сил/интегратора,
нужен отдельный научный протокол, а не этот performance gate.

Неуспех сохраняется; пороги после просмотра результатов не меняются.
Время не гарантирует FPS, truephysicalprecision или скорость иного ПК.
Изменение состава на декоративные частицы и полный перенос на Rust
не входят в эту диагностику.

Дополнительная диагностика разбиения, критерии до запуска: тот же354
научный профиль, 720000 с от t0,10×20шагов против1×200шагов,
прогрев+3повтора, RHS counts отдельно, сравнить конечное время и
per-body/relative Earth–Moon положение/скорость, энергетический баланс.
Начальный checkpoint должен остаться прежним, каждое повторение точное.
Одинаковые допуски не гарантируют одинаковую глобальную ошибку;
сравнение без независимого эталона не сертифицирует ни один вариант.
Крупный пакет меняет сетку снимков и задержку паузы: его меньшую стоимость
не считать оптимизацией прежнего режима и не внедрять автоматически.

Контроль сравнения Newtonian backend до просмотра результатов:354тела,
72000с, те же default GUI допуски; Python/Rust расхождение <0.1м/тело,
<0.01м Earth–Moon и <1e-6м/с (per-body иpair). Независимые скалярные
math.dist/math.fsum E/L/P: relative E иL <1e-10; driftP нормирован
на сумму начальных m|v| <1e-12. Совпадениеbackend+инварианты не являются
полной независимой проверкой траекторий; годоваяJPL точность не заявляется.
