# IAS15 и полная EIH: предварительная проверка совместимости

Протокол177, 15 октября2026. Только исследовательский стенд; без замены
ядра, настроек приложения, зависимости основного окружения и сборки155.
Сначала модельные задачи, затем возможная отдельная проверка Солнечной системы.

## Проверяемая модель и API

Полная взаимная order-reduced EIH 1PN в гармонических координатах,
включая потенциалы всех тел и ньютоновские ускорения источников в поправках.
SI, G из контракта Solar, c=299792458м/с. Модель автономна, t0=0,
модельные IC заданы явно, эфемериды/астрономическая эпоха не требуются.
Скорости принадлежат исходной инерциальной системе; не вычитать новый
COM-дрейф и не выдавать галилеев boost за симметрию 1PN.
Слабое поле: U/c²,v²/c²<1e-4, точечные положительные массы,
без PN-фигур/излучения/вращения/контактов. J2 здесь также отсутствует.

REBOUND5.2.2 IAS15 epsilon1e-9/1e-11, PRS23/min_dt0, exact_finish_time1,
gravity='none', additional_forces присваивает **полное** ускорение nativeEIH.
Обязательный force_is_velocity_dependent=1 обновляет скорости внутренних
стадий. Это прямой SI-адаптер; никаких COM-переносов, pair-переменных или
усечённой центральной GR-поправки в IAS15 нет. Ньютоновская сила не
прибавляется дважды. Запрет неявного перехода на Newton при ошибке.

Python callback через ctypes не должен терять исключения: сохранить первое,
остановить sim, после integrate явно поднять ошибку до выдачи снимка.
Отдельно проверить NaN, форму результата, слабое поле и остановку без
сообщения `Exception ignored on calling ctypes callback`.

## Независимые проверки до численных результатов

1. API: один свободный массивный объект с a=−v/1000с, t0..3000с,
   21равномерная эпоха, v0=(1000,−300,75)м/с,
   r0=(1e6,−2e6,3e6)м. Аналитика v=v0exp(−t/τ),
   r=r0+τv0(1−exp(−t/τ)). Пороги0.001м/1e-6м/с.
   При намеренно выключенном velocityflag сохранить отрицательный контроль;
   он должен не пройти те же пороги. Это API-тест, не модель диссипации Solar.
2. Две равные массы, относительный радиус R=1e8м, μ/(Rc²)=1e-6,
   наклонная плоскость u=(1,0,0), w=(0,.6,.8), постоянный перенос
   (3e8,−2e8,1e8)м, без общего дрейфа. Точная окружность именно
   order-reduced уравнений EIH: η=1/4,
   ω²=(μ/R³)[1−(4+2η)μ/(Rc²)]/[1−(1+3η)μ/(Rc²)].
   Получается подстановкой r·v=0 в равномассовое относительное уравнение,
   а не формулой орбиты Schwarzschild/2PN. Два периода,82эпохи:
   linspace(0,2P,81) плюс .001P. Ошибка каждого тела <0.1м/<1e-4м/с,
   NoetherE/L/P drift<1e-10. Newton-круг с теми же IC не является эталоном.
   Дополнительный отрицательный контроль: Newton-force при тех же IC должен
   нарушить тот же порог аналитической EIH-окружности; сохранить его массивы.
3. Три тела, массы(1e30,3e29,2e28)кг,
   r/AU=[(−.5,0,0),(.8,.5,.1),(−.3,.9,−.4)],
   v/(м/с)=[(30000,−8000,6000),(18000,30000,−3000),(−12000,22000,7000)].
   30суток,61равномерная эпоха плюс1с и72000.125с, без COM-сдвига.
   Независимая scalarEIH из assess_relativity.py, RK45/interleaved AU/year,
   levels(1e-13,1800с),(3e-14,900с),(3e-14,450с), atol1e-17AU/
   1e-17AU-year; дополнительно AU/day с теми же физическими atol.
   Последние уровни и сменаclock должны дать <0.1м/<1e-6м/с;
   начальный roundtrip<0.002м/<1e-8м/с. Кандидаты <1м/<1e-5м/с
   относительно уровня450с/AU-year; NoetherE/L/P drift<1e-10.

Независимые E/P/L получаются из скалярного опубликованного EIH-лагранжиана:
canonical p=∂L/∂v через complex-step, E=Σv·p−L, J=Σr×p.
Сверить с runtime invariants до интегрирования при относительном различии
<5e-14, но не вызывать их при формировании независимых величин.
Дрейф включает O(c^-4) усечение order-reduced модели; NewtonE/P не критерий.
Все нормы/максимумы считаются по всем телам/эпохам.
E нормируется на |E0|, J на |J0|, P на Σm|v0|.

## Сравнение и воспроизводимость

IAS15 и nativeDOP853 ContinuousRun/per-body, rtol3e-14,
atol1e-7м/1e-13м/с, без relativepair в модельных задачах.
dt=P/100 для круга либо3600с для triple, initialIASdt=dt/200,
одинаковые packet20/точные границы выходных эпох, сохранение контроллера.
Два заранее выбранных epsilon, независимая аналитика и scalarRK45,
повторные траектории побитны, исходники/IC/времена/library/actualnativepyd
SHA до/после неизменны. Сохранять отказы, не ослаблять критерии.
Изолированный force callback тестируется отдельно от сравнения интеграторов.

Стоимость после проверок: прогрев и3чередующихся повторения полной
траектории, включая setup/снятие снимков/физический callback/FFI и latch.
Без эталона, invariantdiagnostics, файлов, SHA и JSON внутри таймера.
Предыдущие16–17раз для чистого Newton/Cgravity не переносить сюда.
steps_done IAS15 включает failedsteps, не RHS/acceptedcount.
Сеточная сходимость и совпадение программ не строгая глобальная гарантия.
