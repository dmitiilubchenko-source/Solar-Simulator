# Все 343 астероида DE441: проверенные данные и измерение влияния

Измерения от 10 октября 2026 года, этап подготовки источников 39.
Этот отчёт фиксирует проверку данных и пробных систем до подключения
полного рабочего сценария. Следующий этап уже завершён:
[354 взаимодействующих тела и годовой контроль](asteroids-catalog.md).

## Данные

Для всех 343 астероидов получен контрольный год SB441-N373s:
945 520 байт коэффициентов и директорий вместо всего SPK 982 106 112 байт.
[Диапазоны и SHA-256](../scripts/sb441-343-ranges.json) закреплены;
[оригинальные бинарные записи](../scripts/validation/sb441-343-year.bin)
сохранены отдельно от рабочего пакета. Они доступны офлайн и служат
проверке чтения/сил, не задают будущую траекторию симулятору.

Источники: [SPK JPL](https://ssd.jpl.nasa.gov/ftp/eph/small_bodies/asteroids_de441/sb441-n373s.bsp),
[каталог JPL IOM 392R-21-005](https://ssd.jpl.nasa.gov/ftp/eph/small_bodies/asteroids_de441/SB441_IOM392R-21-005_perturbers.pdf),
[правила формата SPK](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/req/spk.html).
Каталог масс/идентификаторов проверен в [предыдущем аудите](perturber-audit.md).

Чтение учитывает фактические адреса и длительность записей: у Ganymed
интервал 8 суток, у остальных 342 — 32 суток. Все данные — SPK type 2,
коэффициенты положений Chebyshev; скорость вычисляется аналитической
производной с переводом секунд и километров в SI.

Начальные состояния переведены из Sun/J2000 в SSB/Ecliptic J2000
на JD 2461321.5 TDB. Добавлен прежний вектор Солнца.
Состояния всех прежних 16 астероидов воспроизведены побитно.
Пробный набор сохраняет первые 27 масс/положений/скоростей и добавляет
только отсутствующие тела. Полный пробный состав — **354 тела**.
Единственный начальный снимок: [343 состояния](asteroids-343-initial.json).

Сверка NumPy-чтения с CSPICE: 343 тела, 19 239 точек, включая границы записей.
Максимальная разность положения **0.193011 мм**, скорости
**1.158 × 10⁻¹¹ m/s**. Это согласование способов чтения одного источника,
а не независимая оценка физической точности эфемерид.
[Подробная сверка](asteroids-343-source-validation.json).

```powershell
.\.venv\Scripts\python.exe -B scripts/fetch_asteroid_catalog.py
.\.venv\Scripts\python.exe -B scripts/check_asteroid_catalog.py
.\.venv\Scripts\python.exe -B scripts/assess_asteroid_catalog.py --integrate-day
```

Первый и третий инструменты работают офлайн. CSPICE-проверке нужна
библиотека SpiceyPy; на машине разработки она находится в
`.tools/orientation-libs`. Повторное получение всех диапазонов:
`fetch_asteroid_catalog.py --download`. Первичная загрузка была выполнена
с проверкой Content-Range и SHA-256, затем чтение повторено из закреплённого
набора. Первичный загрузчик сначала обнаружил иной интервал Ganymed;
исправленное чтение использует значение директории, а не общий шаг 32 суток.

## Как действует отсутствующая масса

Силы 327 отсутствующих астероидов рассчитаны на прежних 13 годовых эпохах
JPL. Это просмотр поля вдоль эталонных положений, без интеграции орбит
и без подачи будущих векторов в рабочую динамику.
В таблице — максимум модуля **суммы векторов ускорений** на этой сетке.

| Цель | Все отсутствующие 327, m/s² | Остаток после пробного отбора 15, m/s² |
|---|---:|---:|
| Солнце | 1.16693 × 10⁻¹⁴ | 1.12356 × 10⁻¹⁴ |
| Земля | 7.15681 × 10⁻¹⁴ | 6.39560 × 10⁻¹⁴ |
| Луна | 7.15178 × 10⁻¹⁴ | 6.39109 × 10⁻¹⁴ |
| Марс | 1.86297 × 10⁻¹³ | 1.22528 × 10⁻¹³ |
| Луна относительно Земли | 2.62788 × 10⁻¹⁶ | 2.07295 × 10⁻¹⁶ |

Пробный отбор — объединение первых восьми тел по индивидуальной силе на
Землю, на Марс и по разности сил Луна–Земля. Получилось 15 тел:
Hebe, Metis, Parthenope, Euterpe, Amphitrite, Laetitia, Daphne, Ariadne,
Eugenia, Hestia, Pales, Aurora, Lamberta, Dido, Bamberga.
Это экспериментальный критерий, не доказанное оптимальное сокращение.
После отбора значительная часть поля остаётся: одного списка крупнейших
влияний пока недостаточно для достоверного замещения остальных масс.

Для относительного ускорения использована стабильная формула через
`log1p`/`expm1`, чтобы не вычитать почти одинаковые большие силы.
Она отдельно сверена с 80-разрядным Decimal в задаче, где обычное
вычитание float64 даёт ноль. Код относится к диагностике сил.
Прежняя рабочая EIH и её относительные координаты этим этапом не изменены.

Эти максимумы относятся к выбранным эпохам. Из них нельзя получить
гарантированную ошибку орбиты за год или долю улучшения точности.
[Полные силы, ранги и выборка](asteroids-343-assessment.json).

## Цена расчёта

Один вызов силы: медиана пяти серий по 12 вызовов, включая передачу данных
в Rust. Компиляция в время не входит. Отдельно измерена интеграция одних
суток DOP853 с EIH, заданными фигурами и относительной парой Earth/Moon:
rtol 3e-14, допуски положения 1e-5 m и скорости 1e-11 m/s.

| Пробный состав | Рабочая Python EIH | Проверочная Rust EIH | Одни сутки на Python |
|---|---:|---:|---:|
| Прежние 27 | 0.2011 ms | 0.02542 ms | 0.1591 s |
| 42 с пробным отбором | 0.3570 ms | 0.04088 ms | 0.1822 s |
| Все 354 | 30.2315 ms | 2.4181 ms | 3.7120 s |

Это результаты данной машины, не обещание скорости на других компьютерах.
Проверочный Rust здесь — отдельный скалярный эталон разработчика;
рабочий Rust EIH ещё не реализован. На исходной эпохе ускорения Python
и эталона согласуются до **3.975 × 10⁻¹⁸ m/s²** для всех трёх составов.
Однодневный опыт проверяет возможность запуска; его орбита не прошла
годовое независимое сопоставление. Время года из этой таблицы не измерено.

Для 354 тел стоимость Python-силы выросла примерно в 150 раз;
потенциал ускорения на проверочном Rust — около 12.5 раза.
Следующий технический шаг обоснован измерением: перенести рабочую EIH
в Rust, сохранив Python и отдельный эталон, затем проверить полный год
354 тел и численную сходимость. После этого выбирать рабочие сценарии.

## Сохранность источников

Хеш начального снимка:
`50434ff910366e319c9447ede9c7da59fcdac543746cd9840570d3cd05d809b0`.
JSON формируется с фиксированными LF. `.gitattributes` сохраняет байты
научных JSON и исходных бинарных/ASCII записей: автоматическая смена
переводов строк Git не должна менять SHA-256 при переносе checkout.
Глобальные настройки Git не менялись. Проверка чистого фильтра Git
при `core.autocrlf=true` добавлена отдельно.

Койпер, самостоятельное вращение и приливы, высшие гармоники и другие
пропущенные эффекты остаются отдельными этапами. Этот результат не
объявляет текущую модель точной копией DE441 и не меняет старые эталоны.
