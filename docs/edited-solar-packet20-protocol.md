# Год изменённых стартов: настоящие пакеты по 20 часов

16 октября 2026. Протокол этапов 210–213, до новых траекторий.
Продолжение [годовой проверки](edited-solar-year-validation.md).

Проверяются те же три дочерних старта: Sun.mass×1.25,
Earth.position+(1e6,−2e6,3e6) м и Moon.velocity+(100,−50,25) м/с.
Родитель — закреплённый strict checkpoint. Десять тел, SI, исходные
инерциальные оси Ecliptic J2000 и скорости SSB; child.time=0, origin=None.
JD 2461321.5 TDB/DE441 обозначает происхождение, не эфемериду edited-системы.
GM гигантов включает их спутники; повторных масс не добавлять.

EIH 1PN и заданные фигуры J2 Солнца/Земли прежние. Первичные основания:
[EIH action, Vines](https://fiteoweb.unige.ch/~maggiore/GWVol1/EIHLagrangian.pdf),
[DE440/441, Park et al.](https://ssd.jpl.nasa.gov/doc/Park.2021.AJ.DE440.pdf).
Новых сил, приливов, вращения и изменений runtime/default/schema нет.
DOP853, per-body/relative Earth–Moon; rtol=3e-14,
position_atol=1e-3 м, velocity_atol=1e-9 м/с, dt=3600 с, packet_steps=20.

Горизонт — юлианский год, 31557600 с. **440 эпох**:
0, 72000, …, 31536000, 31557600 с. **439 пакетов**:
438 полных по 20 ч и последний 6 ч. Между ними нет промежуточных
запрошенных выходов, сокращающих пакет. Это обычная регулярная сетка
в терминологии общего стенда, а не прежняя сетка через 6 ч.

Использовать неизменный `edited_solar_interval.run`: три reference прежде
кандидатов, затем legacy Python, legacy Rust и continuous Rust.
Reference: независимые scalar Rust EIH и vector J2, AU/year,
EMB+Moon−Earth, RK45; физический c=299792458 м/с.
Уровни (rtol,max_step)=(1e-13,1800с),(3e-14,900с),(3e-14,450с), atol=1e-17.
Счётчики RHS должны расти на обоих уточнениях. Немонотонность сохранять;
последняя разность — чувствительность эталона, не строгая граница ошибки.

Пороги сохраняются: reference по всем телам <1 м/<1e-6 м/с,
Moon−Earth <.01 м/<1e-7 м/с; кандидаты по каждому телу <10 м/<1e-4 м/с,
Moon−Earth <.1 м/<1e-5 м/с. Начальный roundtrip, oracle snapshot,
точные эпохи/массы/Settings, повтор, checkpoint, исходный parent,
SHA source/input/actual DLL/native.pyd/SciPy — прежние проверки.
Три чередующихся полных замера после отдельного повтора; setup и снимки
включены, диагностика и отчёт исключены. Внешняя нагрузка CPU не фиксирована.

После вычислений проверить реальный continuous CLI с packet_steps=20
и настоящий Tk Laboratory с годовой целью и batch=20 в скрытом окне.
Для каждого из трёх стартов проверить все 440 состояний против соответствующего
годового режима побитно через uint64-представление float64. GUI сравнивать
с legacy Rust, CLI — с continuous Rust. Полный CLI вывод/receipt и GUI
состояния сохранить. Общие experimental-флаги CLI не подменять.
Проверка GUI не измеряет отзывчивость и стоимость рисования видимого окна.

С прежней 6h-сеткой сравнить только **148 точно общих эпох**, без интерполяции.
Разности между пакетными режимами — диагностика чувствительности,
не новый независимый эталон и не дополнительный подобранный порог.

Численный отказ сохранять, не менять пороги и не скрывать неудобный режим.
Если расчёт завершён, но критерий не прошёл, допускается завершить аудит
IO и общих эпох, сохранив исходный FAILED и отсутствие общей квалификации.
Для системного исключения/повреждения источников остановить зависимую работу.

Нет нового JPL-сравнения editedIC, интегрированных Noether21 budgets десяти тел,
гарантии любых масс/сближений или всего времени между снимками.
Это отдельная квалификация трёх edited-стартов; исходный nominal strict,
standard solar_sandbox, произвольный batch и ordinary playback GUI не сертифицируются
автоматически. Загрузка final.json создаёт новый контроллер continuous.
